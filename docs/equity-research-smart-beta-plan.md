## 1. 核心判断

下一阶段不是继续增加 package、工具或自由发挥的 Agent，而是把已有组件收成一条能被证据验证的闭环：

```text
真实数据发布与 PIT 验收
  → 公司事实 / 假设 / 反证
  → 有定义、有有效期的研究特征
  → 规则化横截面评分
  → Smart Beta 风格目标与组合约束
  → 优化、整手计划与账户回放
  → 成熟结果、误差归因与策略记忆
  → 候选策略版本的样本外验证、影子运行、人工晋级
```

**主观研究不能直接等同于买卖信号，记忆也不能直接等同于自动调参。** AI 负责理解资料、提出可证伪的研究判断、识别反例和生成受限改进提案；特征映射、评分、优化、回测、结果归因和版本准入由确定性代码控制。

本项目采用“研究驱动 Smart Beta”的定位：价值、质量等透明且稳定的风格规则是主体，研究用于改进风格测量、识别不可比情形和风险条件。如果某个研究信号的收益来自无法解释为风格的个股主动选择，就单独标为研究主动增强层，不能把它全部包装成纯 Smart Beta。

“带记忆的进化策略”指：**记住当时为什么判断、判断哪里错、什么条件下有效；按成熟证据提出新版本，而非每天追逐近期收益改写当前版本。**

## 3. 实施纪律：先收尾，再做融合，不同时摊开多条主线

### 3.1 固定顺序与闸门

```text
A0 基线与契约冻结
  → A1 数据来源与发布契约
  → A2 真实全市场数据验收
  → A3 优化器升级与全规模验证
  → A4 优化—回测—实验登记闭环验收
  → B1 主观研究特征化验证
  → B2 固定规则 Smart Beta 对照实验
  → B3 记忆与候选进化验证
  → B4 前向影子运行与人工准入
```

A1 与 A3 的纯契约设计可交叉讨论，但代码实施一次只推进一个主工作包。A2 未通过前可以做 B1 的少量方法样例，不能宣称全市场策略有效；A4 未通过前不启动大规模策略搜索。

### 3.2 防止实现再次凌乱

1. 不新增顶层 package，不再迁移既有目录；默认复用现有三个 Skill：company-research、equity-valuation、strategy-research，portfolio-risk 负责组合约束解释。
2. 一个工作包只改变一项主要契约或行为，附迁移影响、固定 fixture、测试命令及失败处理；不要把取数、模型重写、Skill 改写放进同一批不可审阅改动。
3. 输入 schema、生产者、消费者和测试同批更新；不保留长期双写/转发壳，也不为了通过门禁静默接收旧字段。
4. 计算留在纯领域模块，网络请求留在 provider/data_sources，持久状态留在 research-workspace，DSH tools 只做边界验证与编排。
5. 每个任务结束记录 done / blocked / evidence / next；真实数据任务每个批次报告成功、失败、覆盖、耗时和下一批，不长期无输出。
6. 修改源码的基线与真实数据 artifact 分开管理；大文件、原始资料和秘密值不进入 Git，Git 只保留 schema、代码、去敏 fixture、摘要及哈希。
7. 不以自动提交作为完成条件。分阶段提交需用户授权；未提交状态使用代码内容 hash 和工作区差异指纹复现。
8. 新建抽象必须有当前消费者。先用现有 artifact 与状态模型承载，不先造通用记忆平台、向量数据库、策略市场或新 Agent runtime。

### A1：建立真实数据证据与发布契约

先按字段核对已有 a-stock、TuShare、CNE6 数据构建路径，不按 provider 数量扩张。优先官方披露及已有授权的历史数据库；免费源缺少 PIT、退市证券或历史成分时，转为明确的数据采购/授权待办，不读取浏览器凭证、不绕过限流、不擅自购买。

| 数据域 | 必需内容 | 不允许的替代 |
|---|---|---|
| 证券与日历 | 历史上市/退市、交易所、板块、ST 状态、交易日历及规则有效期 | 用今天股票列表回放全部历史 |
| 价格与交易状态 | 原始 OHLCV/成交额、停复牌、当天涨跌停价格或权威规则、可交易方向 | 停牌=零收益；未知状态=正常；所有 A 股固定 10% 涨跌停 |
| 股本与行业 | 有效日期对应的总/流通股本、行业分类及版本、必要的修订记录 | 当前股本/行业倒灌历史；流通市值=总市值 |
| 财务 | 原始报告期、公告时间、首次可得版本、修订版本、TTM/MRQ 可重构字段 | 年报直接冒充 TTM；缺公告日按经验日期标成安全 |
| 公司行动 | 分红权利归属、除权、到账、送转/拆并股生效和新增股可卖日期 | 只用一个日期处理分红、送转和结算 |
| 基准 | CSI300/CSI800 历史成分、权重、调样日、价格/全收益序列 | 以当前成分回填；等权篮子冒充指数；价格指数当全收益指数 |
| 研究资料 | 财报、公告、IR 等正文、版本、段落定位、来源时间与内容 hash | 只保存摘要；新闻标题代替正文证据；网页更新时间当首次披露时间 |

**时间契约**
- 分开保存经济有效时间、公告/来源可得时间、系统首次获取时间、修订获取时间、模型/信号实际生成时间。
- 历史重建与当时实际可观测是两种模式。今天拿到有确切历史版本的原始文件可以用于回溯实验，但不能伪称本系统当年就获取并生成了信号。
- 实际运行的 signal availableAt 不早于所有输入可得时间、计算完成时间和正式发布时刻的最大值；回溯实验另存 simulationAsOf 与 reconstructedAt。
- 每个发布包含 universe、字段 schema、来源/授权类别、时间覆盖、质量矩阵、逐证券失败原因、输入/代码/规则 hash 和发布版本。
- 数据修订生成新发布，不能改写历史快照或原实验；CURRENT 只在验收通过后切换。候选验收失败继续保留 last-good，而不是用 partial 覆盖正式版本。

### A2：真实全市场数据验收

**执行阶梯**
1. 20–50 只分层样本：至少覆盖三交易所、金融/非金融、ST、IPO、长期停牌、退市历史、分红送转及低流动性。
2. 历史 CSI300/800 成分全覆盖：验证指数复制、调样、行业权重与风险暴露。
3. 全市场分区构建：按交易日/证券分块，可断点续传，固定限流、重试预算、终止条件和失败清单；只重试失败分区，不无限循环抓取。
4. 对 D 以及事先固定的历史月末、财报披露日、指数调样日、极端行情日发布验收包。
5. 连续 20 个交易日观察增量发布稳定性；不能在本次会话里伪造时间经过，该项属于持续运行验收。

**建议门槛（A0 冻结）**

| 门禁 | 通过条件 |
|---|---|
| 全市场分母 | 每个时点 100% 证券有纳入/排除/缺失原因；与固定权威证券主表核对，无未解释差异 |
| 关键 PIT | 被正式使用的每个价格、财务、行业、基准及状态记录均可证明时点；未来数据污染、错币种、重复键、混复权记录为 0 |
| 必需行情覆盖 | 正常应交易证券日原始覆盖率不低于 99.5%；进入实际优化/成交的证券日覆盖率必须 100%，缺失留痕并阻断，不靠删分母达标 |
| 风险覆盖 | U_eligible 按证券数不低于 98%、按流通市值不低于 99.5%；已持仓及实际计算使用的基准风险质量必须完整，否则拒绝该 run |
| 强制约束输入 | 被使用资产的价格、股数、可卖数量、交易规则及流动性字段 100% 可用；不把未知估成零或放开约束 |
| Descriptor | 42 个逐一有 real/proxy/missing/imputed/unverified 与原始分母；关键模型字段未验证则不能策略准入；分析师等可选数据缺失可停用对应因子，但不能宣称完整商业 CNE6 复刻 |
| 字段抽检 | 分层金标准样本的身份、日期、单位、原始值与来源一致；每类来源至少有独立正文/官方字段核验，而非两个同上游 wrapper |
| 协方差 | 对称、有限、PSD、XFXᵀ+D 重构通过；记录 PSD 修复前后与相对修复幅度，超冻结门槛拒绝，不能只报告修复后最小特征值 |
| 增量运行 | 缺口与修订可定位；失败不替换正式快照；20 日每次计划任务均有成功或明确失败记录，无静默断档 |

总覆盖率以外必须展示交易所、行业、市值、流动性、ST/IPO/退市和年份分层，避免大盘股高覆盖掩盖长尾缺口。价格、财务、风险、研究覆盖使用不同分母，不能混为一个百分比。

**风险模型专项**
- 固定因子字典与有效期，不再用期末活跃风格集合选择历史回归列；历史缺因子显式标记，不能把不存在的暴露补成 0。
- 明确 country/industry 的识别约束，保留回归样本、约束残差与有效样本数。
- 比较预测波动与后续实现波动、标准化残差、组合风险排序和不同市场状态下偏差。评价窗口只用于风险模型校准，不能泄漏到最终策略测试窗。
- “CNE6-inspired 且方法近似已披露”可作为项目模型定义，不能声称与未公开的官方 CNE6 参数完全一致。

**退出**：产出 DataAcceptanceRun，列明 scope、D、历史窗口、输入版本、分层覆盖、抽检证据和各门禁 pass/blocked。只有明确 scope 全通过才可称该 scope 的真实全市场数据验收通过；小样本 smoke、59/60 接口能调用和合成测试不能替代它。

### A3：优化器升级

#### A3.1 输入与状态契约

- 将候选资产、基准全集、现有持仓分开，模型宇宙覆盖其并集。基准不在候选池的权重仍进入基准暴露与主动风险，不能过滤并重归一。
- 缺少研究评分不等于不持有或立即卖出：基准持仓、冻结持仓与候选资格独立，缺分原因明确；rank 只在事前定义的评分池计算，避免无研究资产改变其他资产排名。
- PortfolioStateSnapshot 一次确认现金、应收、总量、可卖数量及批次、估值时点和账户规则；不再只确认 quantity 而由另一个输入随意补现金/可卖量。
- 分域 freshness：价格/交易状态按交易时点，风险按模型发布日期，财务按报告期与修订可得时间，研究按有效期；不把一份年报套入与行情相同的 5 天新鲜度门槛。
- 输入 hash、模型字典、数据来源与质量证明相互校验。格式合法的 sha256、人工传入 `status=ok` 不构成真实性证明。
- 已保存计划是历史草案。对新执行时点重新校验状态、价格、现金和剩余风险预算，生成新的 PlanValidation/拒绝记录，不改写原 OptimizationRun。

#### A3.2 数学与求解

保持 rank α 的 scale=1 和可解释性，不把它升级成单票收益预测。先统一目标函数的量纲，再校准风险/换手权重；记录 rank 效用、风险、成本及各项归一化常数，防止 [-1,1] 分数与很小的日方差直接相加导致风险项几乎不起作用。

推荐继续以因子式凸 QP 为主：

```text
min_w  λrisk · normalized_active_variance(w − benchmark)
       − rank_alphaᵀ w
       + λturnover · turnover(w − current)
       + continuous_cost_surrogate(w − current)
```

- 线性硬约束：预算/现金、权重界、行业偏离、非目标风格带、交易方向、可卖数量、换手、流动性参与率。
- Smart Beta 的目标风格是明确 tilt/暴露目标，不应全部行业/风格中性。区分目标风险与非目标风险；价值/质量溢价不能被全风格中性约束消掉。
- α 不等于预期收益，因此“不交易带/改善阈值”是经训练期校准的效用规则，不把 rank 点数直接当作可覆盖多少 bp 费用。
- 连续解使用凸成本近似；最低佣金、税费、整手后现金由同一 execution 内核精算，报告近似与精算差异。
- OSQP 不支持整数变量，也不直接支持硬二次跟踪误差约束。先保留风险惩罚与独立风险预算校验；若必须求解带硬二次预算的问题，另立一个有测试与依赖审查的 solver 决策，不能伪装为普通 OSQP QP。
- 允许新增“显式软风格目标”，只在 mandate 列出的软项上报告 slack 和惩罚；预算、交易规则、数量、安全边界不能软化。默认仍无松弛。

#### A3.3 整手与不可行性

- 将 100 股作为适用范围内的默认 mandate，不视为所有板块/历史时期唯一交易规则；引入有效期化的 lot/tick/最低申报/零股处置规则。未支持的规则明确排除并留在全市场覆盖报告中。
- 修复流程：交易单位取整 → 现金精算 → 单点及成对交换改善 → 全硬约束重验；保留原有不可交易/不可卖数量。
- 连续不可行、整手搜索未找到可行解、超时、数值不可靠分别报告。局部搜索失败不能宣称数学上已证明整数不可行。
- 在 5–20 只股票的固定小问题上用枚举或已批准整数求解器作独立 oracle，测可行解发现率与效用差距；不要求生产引入混合整数求解器。
- shadow price 仅解释连续问题，需标约束名、尺度、单位与有效状态；原生不可行证书、诊断性最小松弛与求解器对偶不能混用。

#### A3.4 全市场性能与通过条件

- 默认只传 X/F/特异风险及固定 row map，完整 N×N 协方差仅供小样本诊断；避免全量矩阵进入 Agent 上下文。
- 输入输出改为安全的内容寻址 artifact 引用，分块读取、校验 hash/schema/行数与文件类型；不是单纯把 8MiB 上限改大。保留路径和符号链接防护。
- 固定 50/300/800/全市场四档基准，在登记硬件上报告冷/热运行、P50/P95、峰值内存、数值残差、整手成功率；A0 冻结资源预算。建议初值：800 只整链 P95≤60s，全市场≤180s，峰值内存≤8GiB，不满足则先优化或异步分阶段，不悄悄扩大交互超时。
- 固定输入重放的经济结果在冻结容差内一致；不同输入顺序不改变证券映射和目标。跨平台浮点差异保留实际输出 hash，不把经济近似相等说成字节相等。
- 任何标为可用的结果都须硬约束 0 违规、现金按分守恒；极端输入、停牌持仓、全现金账户、窄暴露带、小资金整手均有固定测试。

### A4：将优化器、账户回放与实验登记真正连起来

1. 一次冻结 StrategySpec、mandate、数据发布和代码版本；每天按截止时点读取评分/风险/状态，调用同一个 optimizer 与 rebalance validator，再由同一个 execution 内核结算。
2. 决策时刻与成交时刻分离。t 收盘信息最早用于 t+1 合法成交；不得用当天最终 OHLC、全天成交量或事后确认的停牌状态提前定单。预测性 ADV 与事后容量评价分开。
3. 基准总收益、复制误差、country/industry/style、个股残差、现金/应收、费用与成交时点效应分列；每项独立计算，再做 reconciliation。不能靠一个无限容纳差异的 residual 来证明归因正确。
4. 回测缺失估值维持 missing；未成交订单寿命/取消/重算规则固定；分红 record/ex/pay、股数生效与可卖期一致，退市和收购退出必须有事前规则。
5. 候选收益由登记的参数→信号→优化→成交链生成，只接受相应 BacktestRun 引用，不再把调用方手填收益表当晋级证据。
6. purge/embargo 按交易日与标签真正成熟时间计算；所有标准化、权重、阈值、成本系数及记忆检索策略只在训练/验证范围内选择。
7. TestPartition 单独登记未使用/已使用状态，跨候选和实验版本共享使用记录。已经看过的测试结果可以成为以后训练历史，但不能继续叫同一份“未见测试”。
8. 登记与完成分离并可恢复：中断恢复执行同一冻结任务，不能新开一个“未见测试”；失败也保留证据。重放验证是复算，不是重新选择参数的机会。

**阶段 A 总验收**：真实数据发布→评分快照→优化→整手计划→逐日账户→基准/归因→实验记录可一键离线复算，过去日期结果不受未来输入、未来规则或未来记忆变动影响。此时才进入权益研究融合的大规模实验。

## 5. 阶段 B：主观权益研究如何转成信号

### B1：先验证“研究特征化”，不直接训练自由文本买卖模型

将研究拆成四类，处理方式不同：

| 研究内容 | 系统表达 | 是否直接进分数 |
|---|---|---|
| 可核验事实 | 有期间/单位/来源的 Evidence 与确定性指标 | 可进入已定义的价值/质量特征 |
| 解释性判断 | 锚定 rubric 的离散等级、支持/反证及适用行业 | 仅进入已验证的研究测量特征 |
| 未来假设 | Assumption 与情景、范围、证伪条件 | 不能伪称事实；先实验，未经验证不默认入仓位 |
| 重大风险或证据不足 | 可交易/可研究资格、risk flag、abstain | 不凭一段文字自动硬清仓；硬禁入需确定性规则或人工批准 |

禁止“看多=+1，看空=-1”一刀切，也禁止依据报告篇幅、措辞热情、LLM 自报置信度或重复新闻数加权。

#### 首批研究特征：只选少量可解释维度

| 维度 | 可读研究问题 | 规则化特征候选 | 验证/失效条件 |
|---|---|---|---|
| 价值 | 便宜是否可由可持续现金流支持，而不是周期顶部盈利？ | 行业内估值分位、正常化盈利/现金收益率；DCF 区间折价只作单独实验 | 盈利正常化规则冻结；现金/债务/股数缺失不可推每股价值 |
| 质量与耐久性 | 盈利是否能转成现金，竞争优势是否有经营事实支持？ | 财务质量基线 + 有证据的价格能力/复购/利润稳定性等级 | 必须有反例检查；不能把净利增长重复计入多个因子 |
| 资本配置 | 再投资、回购、并购是在增值还是消耗资本？ | ROIC/再投资匹配、稀释与分红覆盖；执行与历史承诺偏差 | 总回购公告不等于已实施；行业例外单列 |
| 资产负债表/治理 | 风险是被证据确认还是纯叙事猜测？ | 杠杆、流动性、审计/治理事件的分级 penalty 或待审风险门 | 金融企业使用资本/资产质量体系；不套通用工业 Z/M 模型 |
| 论点变化 | 新披露改变了原先哪个假设？ | 同证券、同 rubric 下新旧 ThesisSnapshot 的结构化差分 | 只在新证据可得后生效；单纯涨跌不改业务质量判断 |

首个正式基线仅使用价值与质量；资本配置可作为质量子项。论点变化属于研究增强候选，先观察，不同时上线五个新风险溢价。

金融与非金融使用不同测量模板，但映射为同一类可解释经济维度；不能直接比较银行资本充足率与制造业经营现金流数值。

#### 最小对象与单一事实来源

仅新增必要领域对象，不新增 package 或平行台账：

1. **ResearchFeatureSnapshot**：证券、asOf、生成模式、资料/证据/假设/模型/反证引用、行业模板、feature/rubric/prompt/model 版本、离散等级或数值、quality/coverage、有效期与失效条件。
2. **CrossSectionalScoreSnapshot**：评分池及其 hash、特征输入版本、处理规则、基线分、研究调整分、最终分和 rank α、每个证券 missing/abstain 原因；不能只留最终排行。
3. **StrategyMemorySnapshot**：在该决策时点合法可见的公司/策略/实验记忆引用、冻结 cutoff、检索策略及实际命中、压缩版本和有效性状态。
4. **StrategyRevision**：父版本、经济假设、允许变化的参数、数据/代码/提示词/记忆版本、实验/影子证据、审阅与生效日期、撤回目标。

ResearchFeatureDefinition/rubric 放入版本化 StrategySpec 或注册配置。运行结果进入现有 ModelRun/artifact，来源与结论进入 Evidence/Claim；SignalLedger 扩展一种无 entry/exit 语义的 research-score observation，不能用假确认价/假入场动作伪装成现有技术信号。

`quality` 是数据和测量可信度，`preference score` 是投资排序，二者不能混同。一个负面但证据充分的判断可以是高质量负分；没有资料不是中性意见。

### B2：固定规则 Smart Beta，再测试研究增量

#### 推荐起点

- 日频检查数据、风险与是否需要调仓；研究特征按新披露/失效事件更新，组合采用缓冲带和成本门槛。日频调仓能力不意味着日换手，也不意味着每日重新生成全部研报。
- 主要投资结果期限先固定为 60 个交易日，120 日为慢特征对照，20 日仅诊断衰减/冲击；相应扩展当前结果成熟期契约，不把自然日当交易日。
- 行业内对确定性价值/质量特征做 PIT 标准化和有证据的缺失处理，再形成透明基线分；首版价值/质量等权，不先搜索十几套组合。
- 主观等级先限制在有明确锚点的 ordinal rubric，例如 -2/-1/0/+1/+2，附 unknown；等级是规则结果，不是概率。
- 研究只改进测量或形成受限 overlay，初始研究 overlay 不超过总信号预算 20%，其范围在训练前登记。未覆盖证券走已登记的纯基线策略，并保持 missing/abstain 标记，不把缺失研究填成数值 0 后假装已评价。

概念上：

```text
base_score = 0.5 · value_score + 0.5 · quality_score
score = fixed_fusion(base_score, validated_research_features, eligibility, memory_snapshot)
alpha = average_tied_rank(score, declared_universe) mapped to [-1,1], scale = 1
weights = optimizer(alpha, CNE6_snapshot, SmartBeta_mandate)
```

`fixed_fusion` 首版只允许确定性的有界加权/条件门，不用自由文本生成权重；研究覆盖不齐时不逐股随意重归一分母。单一极端公司叙事不能改变整个市场风险预算。

#### 经济性与对照组

| 实验 | 内容 | 回答的问题 |
|---|---|---|
| E0 | CSI300/800 基准及统一执行条件下的基准复制 | 收益和成本口径是否正确 |
| E1 | 固定价值/质量 Smart Beta，无 LLM | 常规风格基线是否已足够 |
| E2 | LLM 只做证据抽取，评分完全依赖确定性数据 | AI 改善数据理解还是凭空创造信号 |
| E3 | 固定 rubric 的研究增强，无策略记忆 | 主观研究有没有稳定增量 |
| E4 | E3 + 时点合规的公司论点记忆，参数不进化 | 记忆改善一致性、更新精度还是污染判断 |
| E5 | E4 + 受治理的候选版本进化 | 晋级机制是否在未见窗口改善净效用 |

所有组使用相同股票池、数据可见性、优化器、费用、风险预算、研究计算预算和基准口径；至少同时做 matched-coverage 子集与全基线池回测，区分信号增量和“只研究热门公司”的选择偏差。

必须补：ticker/公司名遮蔽、文档改写、段落顺序、重复/同源证据、相互矛盾证据、无新事实的措辞变化、未来字段注入、研究特征打乱、记忆关闭/打乱等负对照。纯打乱信号也显著赚钱时先查泄漏与归因，不宣布模型有效。

## 6. 研究转信号的测试与准入

### 6.1 先测测量质量，再测投资结果

**小规模金标准**：先选至少 60 家跨行业公司、每家不少于 8 个历史披露时点，包含负面案例、反转、低关注度及退市/困境样本；公司和事件在看结果前选定。所有重要判断至少两人独立标注或复核，争议保留，不拿 AI 自己的共识当金标准。

建议在实验开始前冻结的测量准入：
- 关键数值、日期、单位和原文支持的硬错误为 0；重要 claim 可定位原文，coverage=100%。
- 信息不足时明确 abstain；missing 与 neutral 混淆为硬失败。
- 至少 3 次固定配置重复运行；结构化等级一致率≥90%，有分歧的样本复核或降级；输出 token/延迟/成本一并报告。
- ordinal 人工一致性采用 weighted κ 等指标，建议 κ≥0.6；若人类自身一致性低，先修 rubric，不把标准放宽到模型表现。
- 无新事实的文字改写不能显著改变评分；研究更新只修改受新证据影响的维度。

这些是候选门槛，不是已经达到的事实。通过抽取质量不代表通过投资有效性。

### 6.2 历史 LLM 回放的特殊泄漏

现代模型可能在参数中知道历史公司结果，单靠限制检索日期不能消除这种信息。必须区分：
- **历史真实记录**：当时已经生成、保存且可证明时间的研究/信号。
- **今天对历史资料的回溯生成**：用于方法和工程研究，标为 retrospective，不能无条件称严格样本外。
- **前向影子信号**：今天冻结，未来观察结果；这是 AI 研究增量最重要的验证证据。

回溯生成时用原始时点资料、无未来修订、尽量遮蔽身份、记录模型版本/知识截止已知范围；遮蔽失败或仍可能被识别的样本标注风险。不能伪造历史 generatedAt，也不能把今天总结出的教训塞进过去的 memory。

### 6.3 投资验证与停止条件

- 主指标：相同风险预算下、含成本的基准超额与相对 E1 的增量；同时展示年化波动、回撤、跟踪误差、换手、容量、持有期与目标风格暴露。
- 诊断：按日期计算截面 Rank IC/分组收益与衰减，分析行业、风格及个股残差贡献；不得把所有 stock-day 混池相关性当截面 IC，也不得把 country/基准复制残差算成选股能力。
- 推断：按日期区块 bootstrap/HAC 处理重叠持有期和横截面相关，多重尝试记录完整；有效样本数不是证券行数。
- 时间划分：训练→验证选版本→外层测试；至少 3 个不重叠外层测试段，覆盖不同市场状态。最终保留一段真正未见区间；每轮候选数量和总尝试预算事先登记，首轮每条假设最多 12 个配置。
- 晋级建议：相对 E1 的主要净增量在区块置信区间下界仍大于 0、绝大多数外层窗口方向一致、不能靠单行业/单年份或明显超额风险解释，成本翻倍压力下仍不失去全部增量。未达到则保持 experimental，不宣布无效，也不强行上线。
- 当研究 overlay 无稳定增量但抽取质量提高，可仅将 AI 用于研究生产与风险解释，组合维持固定 Smart Beta。这是合法实验结论，不是项目失败。

## 7. 带记忆的进化策略

### 7.1 记住什么

| 记忆层 | 保存内容 | 更新规则 |
|---|---|---|
| 公司论点记忆 | 旧判断、假设、证据、反证、承诺与兑现、有效期 | 新证据产生新版本，不能覆盖旧结论；优先复用 ThesisSnapshot |
| 策略经验记忆 | 哪个 rubric/特征在什么行业、状态、质量条件下有效或失败 | 只纳入已经成熟且可追溯的结果；区分基本面验证与市场收益 |
| 实验负记忆 | 失败候选、重复想法、泄漏/容量/交易约束问题、为何拒绝 | 永久保留索引，防止只记住赢家和重复搜索 |
| 运行/人类纠正记忆 | 字段映射错误、方法纠正、人工审阅原因 | 数据修复、方法规则与投资假设分开；用户喜欢某份报告不等于它有收益预测能力 |

不默认引入向量数据库。先用可检索的结构化记录和标签，在现有 workspace/artifact 内建立单一记忆索引；压缩摘要引用原记录，不能代替或删除原记录。

### 7.2 时间与检索规则

- 每次信号绑定 memorySnapshotHash；检索只返回 `availableAt <= decisionAt` 且在该时点有效的记忆。
- 结果记忆还要求 `outcomeMaturityAt <= memoryCutoff`；t 时点未成熟的 60/120 日收益不能用于 t 的策略更新。
- 记忆可记录“未知、失效、矛盾、被撤回”，不只有正面总结；被否定的结论保留反证，不从历史消失。
- 同源转载合并，不能把多篇重复材料当作独立票数；retrieval policy、返回条目、过滤理由和压缩版本必须进入审计。
- 以 as-of 同行、行业与事实特征匹配，不用未来最佳收益案例做检索条件；公司名记忆要做遮蔽/跨公司泛化对照。
- 污染的历史记忆使对应实验失效；重新运行生成新实验，不能在原结果上偷偷替换记忆。

### 7.3 如何进化

```text
成熟结果 + 人工事实纠正
  → 错误归因（资料/抽取/判断/规则/组合/成交/市场状态）
  → 有经济假设的 StrategyRevision 候选
  → 固定测试与负对照
  → 验证集比较
  → 未见外层测试
  → shadow
  → 人工 approved，未来日期生效
```

- 首版只允许修改 rubric 映射、组合权重、缓冲/持有阈值、记忆检索/衰减规则之一；每个候选尽量只变一类，便于因果归因。
- 新经济因子、模型类别、数据源和风险预算变更走新的研究假设，不由同一个自动搜索顺手加入。
- 事实记忆按事件更新；表现校准按月检查，正式策略候选默认按季度评审且必须满足标签成熟和有效样本门槛，不每天根据收益修正。
- 小样本按预登记规则收缩到固定基线，不能用 LLM 自报信心或某次高收益放大权重；稀疏行业不单独拟合。
- Champion/Challenger 共用数据与执行器，各自保存自己的历史组合和合法记忆，不用冠军后验知识帮助过去的挑战者。
- 新版本生效前加入真实切换成本、持仓迁移与不可交易约束。旧版本可回放，新版本可撤回；回滚只影响未来决策，不改历史业绩。
- 程序可自动提出/评估候选，但修改正式策略、风险 mandate 或晋级 approved 需要人工确认。即使 approved，本阶段仍只有模拟与 dry-run。

### B3/B4 验收

1. 同一原始数据、策略版本和 memory cutoff 可复算相同结构化评分与经济结果；无需在线再次调用 LLM 才能重放已经保存的推断。
2. 注入未来记忆、未成熟标签或事后纠正时，历史查询拒绝或不变；压缩前后证据引用与状态可追溯。
3. E4 相对 E3 的改善需证明不是更多 token、更多资料、不同股票池或未来信息造成；E5 相对冻结 E4 需要独立前向证据。
4. 错误教训、低质量输入及失效研究不会自动晋升为跨公司事实或策略规则；记忆污染可隔离、撤回并影响明确的下游 run。
5. 先运行不少于 60 个交易日 shadow 验证流程，再等主要 60 日结果成熟；120 日结论必须等待相应成熟。影子期长度不自动等于统计显著性，样本不足继续观察。

## 10. 统一验收与非目标

每个工作包的最低工程验证：对应小范围测试、跨语言 schema/hash fixture、`pnpm check`、负路径与恢复测试；涉及 UI 再实际启动浏览器操作。数据验收另运行受控 live probe/分批重建及冻结回放，模型收益评估另运行预登记实验，三者不能互相替代。

本计划执行时必须产出三种独立结论：
1. **工程可用**：代码、契约、运行时与审计正确。
2. **数据可用于某用途**：指定 universe/日期/字段的真实来源、PIT 与覆盖已验收。
3. **策略有证据支持**：相对固定 Smart Beta 基线的样本外/前向增量成立，或仍不足。

明确不做：新增交易权限、无限自动调参、无界多 Agent 投票、无来源的买卖打分、把策略赢家总结自动写成真理、先建重型记忆平台、用模型历史常识伪装 PIT、为了收益好看静默删证券/期间/失败试验。

完成目标不是“AI 会写更多研报”，而是：同一家公司在同一时点为什么得这个分、这个分如何改变目标风格和组合、付出什么成本、后来哪里判断错、哪条新证据允许更新下一版本，都能沿一条证据链回答。
