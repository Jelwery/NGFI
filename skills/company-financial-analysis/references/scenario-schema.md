# scenario.json 格式规范

估值脚本 `calc_valuation.py` 的 `--scenario-file` 参数必须传入此文件。脚本不提供默认值。

## 完整示例（三七互娱）

```json
{
  "pessimistic": {
    "wacc": 0.10, "term_g": 0.02,
    "rev_growth": [-0.05, -0.03, -0.01, 0.0, 0.01],
    "gm": [0.73, 0.72, 0.71, 0.70, 0.70],
    "sm_rate": [0.52, 0.52, 0.51, 0.50, 0.50],
    "admin_rate": 0.035, "rd_rate": 0.045, "other_inc_rate": 0.01
  },
  "neutral": {
    "wacc": 0.09, "term_g": 0.025,
    "rev_growth": [-0.02, 0.02, 0.04, 0.05, 0.05],
    "gm": [0.75, 0.75, 0.75, 0.76, 0.76],
    "sm_rate": [0.49, 0.48, 0.48, 0.47, 0.47],
    "admin_rate": 0.035, "rd_rate": 0.045, "other_inc_rate": 0.01
  },
  "optimistic": {
    "wacc": 0.085, "term_g": 0.03,
    "rev_growth": [0.05, 0.08, 0.10, 0.10, 0.08],
    "gm": [0.77, 0.78, 0.79, 0.79, 0.79],
    "sm_rate": [0.47, 0.46, 0.45, 0.44, 0.44],
    "admin_rate": 0.03, "rd_rate": 0.04, "other_inc_rate": 0.01
  }
}
```

## 字段说明

三个情景（pessimistic / neutral / optimistic）**全部必填**。每个情景包含：

| 字段 | 类型 | 必填 | 说明 |
|------|:---:|:---:|------|
| `wacc` | float | ✅ | 折现率。6%-12%为合理区间。需×股权成本×债务成本加权 |
| `term_g` | float | ✅ | 永续增长率。不超过GDP长期增速（2%-3.5%）。wacc - term_g ≥ 2% |
| `rev_growth` | float[5] | ✅ | 未来5年每年收入增速。如 [-0.02, 0.02, 0.04, 0.05, 0.05] |
| `gm` | float[5] | ✅ | 未来5年每年毛利率。如 [0.75, 0.75, 0.75, 0.76, 0.76] |
| `sm_rate` | float[5] 或 float | ✅ | 未来5年每年销售费用率。可以是5个值的数组或单个值（逐年相等） |
| `admin_rate` | float | ⚠️ | 管理费用率。可选，默认 0.035 |
| `rd_rate` | float | ⚠️ | 研发费用率。可选，默认 0.045 |
| `other_inc_rate` | float | ⚠️ | 其他收益/营收。可选，默认 0.01 |
| `tax_surcharge_rate` | float | ⚠️ | **行业特化**：税金及附加/营收。白酒约0.146，一般制造业约0.01-0.03。可选，默认 0 |

**行业特化参数说明**：`tax_surcharge_rate` 用于建模财报中"税金及附加"科目的影响。对白酒（消费税从价+从量）、烟草等高税行业，这是重大成本项（可达营收14-15%），必须在 scenario 中设置。对大多数制造业公司仅1-3%可忽略。此参数从营收中直接扣除，影响EBIT和FCF。

## 编写指引

**不是随便填数字**——三情景的每个参数都应有前五个阶段的分析依据：

- **rev_growth**：来自阶段2的历史收入增速分析 + 阶段1的行业增速判断 + 阶段3的合同负债趋势
- **gm**：来自阶段2的毛利率历史趋势 + 成本归因（分成成本刚性/代理比例等）
- **sm_rate**：来自阶段2的销售费用率趋势 + 买量效率判断
- **wacc**：来自阶段6的CAPM计算（Rf+β×ERP+公司特定风险溢价）
- **term_g**：基于行业长期增长前景，不超过GDP增速

悲观、中性、乐观三情景应有**独立的逻辑**，不能只是"中性×0.7"——每个情景代表一种可能的经济/行业/公司状态。分析报告中必须解释每种情景的假设逻辑。

## 与 state.json 的关系

scenario.json 中的增速/毛利率/费用率/WACC是**分析师判断**，不包含capex等脚本推导值。但 `calc_valuation.py` 运行时会从 `_data.json` 实时推导 capex、税率、折旧、股本等。增量更新时，`state.json` 的 `last_valuation` 中**必须同时保存 scenario 参数和脚本推导值**（如 `capex_avg`），否则下一次增量更新的估值桥接会因 capex 变化而失真。
