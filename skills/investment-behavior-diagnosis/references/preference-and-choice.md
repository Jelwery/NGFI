# 偏好与选择：从前景理论到投资决策

本文件用于需要精确解释参考依赖、累积前景理论（CPT）、心理账户、处置效应、短视损失厌恶、路径依赖或时间不一致的任务。理论是生成候选机制的工具，不是根据一个结果给人贴标签的许可证。

## 1. 理性基准与行为问题

标准期望效用以最终财富和状态概率评价选择。行为金融研究的关键补充不是“人都不理性”，而是某些偏离具有可重复的方向，并会随参考点、描述方式、反馈频率和情境变化。

诊断时先问：

- 如果忽略买入成本，当前各选项的前瞻收益、风险和约束是什么？
- 用户是在评价最终财富，还是相对某个参考点的得失？
- 同一选择换一种描述后，偏好是否会反转？
- 这是稳定偏好、临时情绪，还是理性约束造成的行为？

## 2. 参考依赖与价值函数

前景理论把结果写成相对参考点的变化 x，而不是只看最终财富。常见的示意形式是：

~~~text
v(x) = x^α                    当 x >= 0
v(x) = -λ(-x)^β               当 x < 0
~~~

三个核心性质：

1. 参考依赖：同一最终财富可因起点不同被编码成收益或损失。
2. 敏感性递减：离参考点越远，新增一单位变化的心理影响通常越小；收益区常呈凹形，损失区常呈凸形。
3. 损失厌恶：参考点附近，等量损失通常比等量收益影响更大，λ 用来刻画这种不对称。

Tversky 与 Kahneman（1992）的经典参数估计常被写成 α≈β≈0.88、λ≈2.25。它们来自特定实验、模型和估计方法，不是自然常数，也不能据此声称某位用户“损失痛苦正好是 2.25 倍”。在个体诊断中，参数只用于解释模型形状；若无专门估计，应使用定性语言。

参考点可能来自买入成本、近期高点、预算、目标收益、同伴表现、上次账户峰值或事前计划。成本价在税务或绩效评估中可能有现实意义，因此“关注成本”不自动等于锚定偏差。

## 3. 概率加权与四重模式

CPT 不直接用客观概率 p，而使用决策权重。Tversky 与 Kahneman（1992）的一类函数为：

~~~text
w(p) = p^γ / (p^γ + (1-p)^γ)^(1/γ)
~~~

收益和损失可使用不同参数。常见形状是对小概率给予相对较高权重、对中高概率给予相对较低权重，但端点、参数与任务描述都会影响结果。概率加权不是“人总会高估所有风险”。

价值函数形状与概率加权共同产生四重模式：

| 区域 | 常见倾向 | 典型情境 |
|---|---|---|
| 高概率收益 | 风险厌恶 | 更偏好确定获利 |
| 低概率收益 | 风险寻求 | 彩票式机会 |
| 高概率损失 | 风险寻求 | 为避免确认损失而赌一把 |
| 低概率损失 | 风险厌恶 | 为小概率灾难购买保险 |

这是总体预测，不是每个投资者在每次交易中的必然反应。财富约束、杠杆、流动性和效用曲率也可能产生相似选择。

## 4. 编辑、框架与心理账户

早期前景理论把决策分为编辑与评估。编辑过程会编码、合并、分离、约简结果；不同框架因此可能让相同经济结果得到不同选择。

心理账户指人们按来源、用途、资产或时间把经济结果分账，而不是总以完整组合评价。常见现象包括：

- 把浮盈当作“庄家的钱”，盈利后提高风险；
- 把回本设为单独目标，亏损后接受原本不会接受的风险；
- 把少赚编码成损失，从而产生卖飞焦虑；
- 逐只股票评价盈亏，忽略组合层风险。

分账有时是有用的自控或预算机制。例如应急资金与长期资金分离可能降低挪用风险。诊断问题不是“有没有账户”，而是账户边界是否扭曲了当前目标与约束。

## 5. 处置效应与可识别性

处置效应通常指投资者相对更愿意实现盈利、延迟实现亏损。前景理论、实现效用、税务、再平衡、信息质量和交易约束都可能影响观察结果。

Odean 式度量使用每个卖出机会日的已实现与账面机会集：

~~~text
PGR = Realized Gains / (Realized Gains + Paper Gains)
PLR = Realized Losses / (Realized Losses + Paper Losses)
~~~

只有平仓记录不能重建当日未卖持仓的 paper gains/losses，因此不能计算该定义下的 PGR/PLR。平均盈利持有期短于亏损持有期只是描述性线索，还要检查：

- 样本是否只保留已平仓交易；
- 不同策略、资产和市场状态是否混在一起；
- 税务损失实现、止损规则和再平衡是否解释卖出；
- lot matching 与费用是否明确；
- 比较是否基于事前可用信息。

## 6. 短视损失厌恶

短视损失厌恶（Benartzi 与 Thaler，1995）把损失厌恶与频繁评价结合：长期资产在短窗口内更常呈现亏损，频繁查看会反复触发损失体验，从而改变愿意承担的风险。

不要把“每天约一半时间看到亏损”等数字当普遍事实；概率取决于资产分布、样本期、观察窗口与计量口径。也不能由“频繁看盘”直接推断损失厌恶，因为用户可能在做流动性管理、风险监控或短周期策略。

可检验的问题是：控制信息和风险后，降低反馈频率是否减少计划外修改，并改善规则遵守或主观困扰。收益改善不是必然结果。

## 7. 路径依赖

近期盈亏可能改变后续风险承担：

- house-money effect：近期盈利被单列后，后续风险承担可能增加；
- break-even effect：亏损后更愿意接受能“回本”的赌局；
- snake-bite effect：重大损失后风险承担可能下降。

这些效应可以并存，方向受损失规模、能否回本、财富约束和时间间隔影响。不要把“赢后加仓”或“亏后保守”机械映射为一个固定效应。

## 8. 时间不一致与预承诺

长期计划与临近行动时的偏好可能不一致。原因可能包括即时情绪、双曲贴现、反馈显著性、环境诱因或计划本身不完整。

预承诺可以降低临场改写规则，但也可能在信息真正变化时阻止合理更新。因此规则应包含：

- 预先定义的触发条件；
- 允许更新的证据类型；
- 冷静期或第二人复核；
- 紧急流动性例外；
- 定期审查和撤销条件。

## 9. 禀赋效应与维持现状

持有本身可能提高主观估值，维持现状也可能因转换成本、税务或不确定性而更有吸引力。使用“空仓测试”时要补上现实摩擦：若今天持有等值现金，在考虑税费、流动性、组合暴露和信息后，是否仍会建立相同头寸？

空仓测试不是自动卖出规则，而是暴露路径依赖的对照问题。
