# 行为诊断生产版与 V2 兼容矩阵

本文件记录从共同基线 `da101d13095c413e7904d4eb171afd11d01c97b5` 合并根目录 V2 Skill 时的保留决策。canonical Skill 始终是 `skills/investment-behavior-diagnosis/`。

| 能力 | 生产版 | 根目录 V2 | canonical 结论 |
|---|---|---|---|
| 证据分层与置信度 | 完整，含六级证据与低/中/高边界 | 较简略 | 保留生产版 |
| 候选机制与竞争解释 | 强制七项诊断单元 | 要求可证伪替代解释 | 保留生产版并在最高优先级控制层重申 |
| PGR/PLR | 严格要求卖出日机会集，缺失时不可计算 | 理论资料覆盖公式 | 保留生产版边界，V2 资料作为兼容 reference |
| 工具使用 | 三个白名单行为工具，保留 provenance、status 与 limitations | 无等价受控工具 | 保留生产版 |
| 状态机 | 按置信度和缺口叙述 | `needs_input`、`data_conflict`、`ok`、`not_a_bias` | 吸收到 canonical 控制层 |
| 理性零假设 | 通过竞争解释体现 | 显式“理性行为是零假设” | 吸收到 canonical 控制层 |
| 核心机制数量 | 通常 1–3 个 | 最多 3 个 | 固定最多 3 个 |
| 对抗指令防护 | 由诊断与安全边界约束 | 显式禁止覆盖规则和结论先行 | 吸收到 canonical 控制层 |
| 文件写入 | 没有写入需求 | 默认不创建文件 | 吸收到 canonical 控制层 |
| 交易建议边界 | 禁止具体买卖、仓位和杠杆指令 | 额外禁止目标价与择时 | 采用二者并集 |
| 隐私与心理健康 | 明确不索取凭据，急迫/自伤风险优先支持 | 无更强约束 | 保留生产版 |
| 理论深度 | 五份按证据职责组织的正式 reference | 三份综合 toolkit | 正式 reference 保留；V2 三份以 `v2-*-toolkit.md` 兼容名保留 |

结论：canonical 版本是生产版的严格超集。没有用 V2 覆盖生产版；V2 独有控制约束已进入最高优先级段，三份原始理论资料保持内容不变并可通过 `finance_behavior_reference` 的固定 topic allowlist 读取。
