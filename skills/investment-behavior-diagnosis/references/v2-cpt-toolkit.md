# 前景理论完整工具箱 (Prospect Theory Toolkit)

## 一、价值函数 v(x)——核心三特征

前景理论用 v(x) 替代期望效用理论的 u(W)，根本区别：评估的是**相对参考点的得失**，而非绝对财富水平。从"绝对论"到"相对论"。

### 1.1 参考点依赖 (Reference Dependence)
- 满意感来自相对参考点 R 的收益或损失
- > R = "得"，< R = "失"
- 张赚20万→100万 vs 李亏60万→100万：客观财富相同（100万），心理完全不同
- 参考点通常是现状、期望水平或买入成本

### 1.2 敏感性递减 (Diminishing Sensitivity)
- **收益区 v 凹**：捡50又捡50 → v(50)+v(50) > v(100)，分开享受两个小收益优于一次大收益（"两小口品"）
- **损失区 v 凸**：丢50又丢50 → v(-50)+v(-50) < v(-100)，一次大损失优于分开小损失（"一大口吞"）
- 含义：收益→风险厌恶（凹），损失→风险喜好（凸）

### 1.3 损失厌恶 (Loss Aversion)
- 损失区比收益区**更陡**，λ ≈ 2.25
- 捡100的喜悦 < 丢100的痛苦，等值损失的痛苦≈收益愉悦的2.25倍
- **Rabin (2000) 批评与CPT反驳**：期望效用最大化者若在所有财富水平拒绝(110,1/2;-100,1/2)，则也必须拒绝(20,000,000,1/2;-1000,1/2)——荒谬。但CPT不会：前者V=-32.5（拒绝），后者V=1,118,519（绝对接受）。因为v(x)关注相对参考点的得失而非绝对财富。
- 50-50混合赌局证据：人们通常要求收益≥损失约2倍才接受

### 1.4 价值函数公式
```
v(x) = x^α                    x ≥ 0 (收益)
v(x) = -λ·(-x)^β             x < 0 (损失)
α = β = 0.88, λ = 2.25
```

## 二、四重风险偏好模式 (Fourfold Pattern)

|           | 收益 Gains                          | 损失 Losses                              |
|-----------|------------------------------------|------------------------------------------|
| **高概率** | **风险厌恶**：落袋为安               | **风险喜好**：赌一把避免确定损失           |
|           | CE < E[X]，如 c(100;0.95)=78 < 95  | \|c(-100;0.95)\|=84 > 95                  |
| **低概率** | **风险喜好**：买彩票                 | **风险厌恶**：买保险                       |
|           | CE > E[X]，如 c(100;0.05)=14 > 5   | \|c(-100;0.05)\|=8 > 5                    |

**核心洞见**：同一人在不同概率和得失组合下，可以既是风险厌恶者又是风险喜好者——这在期望效用框架下完全不可能。CPT用同一组参数（α=β=0.88, λ=2.25, γ=0.61, δ=0.69）解释同一人的"矛盾"行为。

**现实应用**：
- 困境银行→监管者倾向于等待（损失区高概率→风险喜好）→1998/2008反复出现
- 彩票购买（收益区低概率→风险喜好）+ 保险购买（损失区低概率→风险厌恶）→同一人同时买彩票和保险
- 投资者面对盈利→风险厌恶→过早止盈；面对亏损→风险喜好→过晚止损

## 三、决策权重函数 w(p)

不按客观概率，按**主观扭曲权重** π(p)。

### 3.1 反S形特征
- p→0 附近凹：**高估小概率**——π(0.001) >> 0.001→彩票效应
- p→1 附近凸：**低估中高概率**——π(0.5) < 0.5→中等概率被压低
- π(0)=0, π(1)=1

### 3.2 权重函数公式（Tversky & Kahneman 1992）
```
w+(P) = P^γ / [P^γ + (1-P)^γ]^(1/γ),  γ = 0.61 (收益)
w-(P) = P^δ / [P^δ + (1-P)^δ]^(1/δ),  δ = 0.69 (损失)
```

### 3.3 概率加权对风险偏好的反转
- 高估小概率效应可以**反转**价值函数描述的风险偏好
- 价值函数说收益区风险厌恶，但+低概率→彩票效应→风险喜好
- 价值函数说损失区风险喜好，但+低概率→保险效应→风险厌恶
- 这是四重模式中"低概率反转"的数学基础

## 四、决策两阶段：编辑 + 评估

### 4.1 编辑阶段 (Editing Phase)
决策者如何**描述和框定**选择方案：
- **编码**：将结果定义为相对于参考点的收益或损失
- **组合**：相同结果的概率相加
- **隔离**：无风险部分与风险部分分开
- **取消**：剔除不同前景的共有部分

编辑操作顺序随选择集和显示格式变化→**框架效应(Framing Effect)**——同一客观问题编辑方式不同→不同选择。

### 4.2 Thaler框架实验
方案一：A抛硬币(39,21) B直接得30 → 多数选B
方案二：C抛硬币(39,21) D不抛直接得30 → 多数选C
B和D客观相同（都得30元），但表述不同→系统性选择逆转。

### 4.3 评估阶段 (Evaluation Phase)
基于编辑结果做最终决策：
- v(x)：评估相对得失
- w(p)：主观扭曲概率
- 综合倾向：最小化损失或最大化收益，取决于编辑方式

### 4.4 助推 (Nudge) — Thaler & Sunstein (2008)
框架效应的自然延伸：如果问题的"编辑方式"系统性影响选择，那么通过改变选择架构（choice architecture）可以在不限制自由的情况下引导更好的决策。

核心原则：
- 不用强制手段，从细节入手温和改变选择
- 禁止垃圾食品不是助推，把水果放在显眼位置是助推
- 改变注意力资源的分配方向——利用系统 1 的懒惰来帮助系统 2

投资中的应用：
- 默认选项的力量：自动加入养老金计划（opt-out）远比自愿加入（opt-in）参与率高
- 信息呈现方式：把年化收益率而非单日涨跌幅放在首页，减少 MLA
- 改变环境而非改变意志力：删掉交易 app 比每天和自己斗争更有效

## 五、心理账户 (Mental Accounting) — Thaler (1980)

人们将资金放入不同"心理账户"，而非整体评估。

### 5.1 整合与分离规则
- **收益宜分离**：v(x) + v(y) > v(x+y)——"两小口品"
- **损失宜合并**：v(-x) + v(-y) < v(-(x+y))——"一大口吞"
- **小损失+大收益→合并**：净收益，一次感觉好
- **小收益+大损失→分离**："silver lining"，保留一线希望

### 5.2 赌场赢利效应 (House Money Effect) — Thaler & Johnson (1990)
- 决策前有盈利→增加随后的冒险行为
- 机制：把赢来的钱视为"别人的钱"或"赌场的钱"→心理账户隔离→更敢冒险
- 通俗："慷他人之慨"

### 5.3 保本效应 (Break Even Effect)
- 如果冒险的结果能弥补之前损失→冒险行为增加
- 机制：建立"回本"心理账户→不把亏损当最终结果→"再赌一把就能回本"
- 含义：路径依赖可能需要**很强的自制力**才能克服

## 六、处置效应 (Disposition Effect) — Shefrin & Statman (1985)

### 6.1 定义
过早卖出盈利股票 + 过久持有亏损股票。

### 6.2 度量
- PGR (Proportion of Gains Realized) = 已实现收益 / (已实现收益 + 账面收益)
- PLR (Proportion of Losses Realized) = 已实现损失 / (已实现损失 + 账面损失)
- 处置效应 = **PGR/PLR > 1**——更愿实现收益而非损失

### 6.3 前景理论解释
- 盈利→参考点上方→v凹→风险厌恶→卖出锁定收益
- 亏损→参考点下方→v凸→风险喜好→持有等待回本

### 6.4 文化差异
- 华人投资者参考水平对盈利不敏感→更容易"赚够了"→处置效应更强
- Barber et al. (2007) 台湾证据；Chen et al. (2007) 新兴市场证据
- 姚京、严珅、李端 (2013)：香港居民 λ=2.62, α=0.691→损失厌恶比美国更强
- 美国投资者：更新心理账户后旧账户不重要；华人：更关注各账户间联系

### 6.5 专业交易者也一样
Coval & Shumway (2005)：芝加哥期货专业交易者→上午亏损→下午承担更高风险。损失厌恶交易者价格反转速度显著更快。

### 6.6 Grinblatt & Han (2005) —— 处置效应→市场均衡→动量
这是连接个体偏差（处置效应）与市场价格（动量效应）的关键模型，发表于 JFE。

**模型结构**：两类投资者共存——
- **理性投资者**：根据基本面与价格的差距交易
- **PT/MA投资者**（前景理论/心理账户投资者）：额外关注当前价格相对历史参考成本 R_t 的得失——处于盈利时倾向卖出，处于亏损时倾向持有

**均衡价格 = 基本面与参考点的加权平均**。处置效应投资者的存在使价格偏离基本面→产生**价格对信息的反应不足**。

**横截面动量效应**：
- 亏损股持有者不愿在坏消息后充分卖出→价格调整不充分→随后继续下跌→形成动量
- 盈利股持有者过早卖出→价格上涨受阻→好消息没有完全被价格吸收→随后补涨→也形成动量
- 处置效应不仅是个体偏差，还通过市场均衡产生系统性的价格可预测性

**关键含义**：
- 处置效应≠"愚蠢的错误"，它通过市场均衡创造可观测的定价模式
- 动量策略（买入赢家/卖出输家）的行为金融学基础之一
- 解释了为什么市场层面会出现与个股处置效应方向一致的价格趋势

## 七、MLA 短视损失厌恶 (Myopic Loss Aversion) — Benartzi & Thaler (1995)

### 7.1 解释股票溢价之谜 (Equity Premium Puzzle)
- Mehra & Prescott (1985)：1926-1992 美股年实际收益≈7%，短期国库券<1%，溢价≈7.4%
- 解释此溢价需要风险厌恶系数>30，但实际≈1
- MLA解释：**短评估期 × 损失厌恶 → 降低股票吸引力 → 要求极高溢价**

### 7.2 评估期效应
- **1个月**：P(亏损)≈40%→损失厌恶强烈→股票不吸引人
- **1年**：P(亏损)≈30%→股票和债券前景值相当（无差异）
- **5年**：P(亏损)≈10%→股票吸引力大幅上升
- **10年**：P(亏损)极低→几乎没有MLA

### 7.3 核心洞见
MLA核心**不是**不愿承担风险，而是**频繁评估放大了损失厌恶**。拉长评估期是降低MLA最直接的方法。

### 7.4 现实教训：中国熔断机制 (2016.01)
- 1月4日首个交易日：触及5%→暂停15分钟→"再不卖就来不及了"的恐惧→恢复后直奔7%→大面积跌停
- 1月8日即宣布暂停
- 行为解释：熔断人为缩短了评估期→MLA被机制放大→恐慌自我实现

## 八、路径依赖 — Thaler & Johnson (1990)

之前的决策结果影响之后的风险态度——决策不仅取决于**现状**，也取决于**如何达到现状**。

### 三种效应
1. **赌场赢利效应**：之前盈利→风险承担增加（"慷他人之慨"）
2. **保本效应**：有机会弥补之前的损失→风险承担增加（"再赌一把回本"）
3. **蛇咬效应**：之前亏损且无法弥补→风险承担减少（一朝被蛇咬）

### 含义
路径依赖可能引发非理性的风险承担波动，需要很强的自制力才能稳定决策质量。这进一步强化了时间不一致性——不仅当下偏好与计划不同，过去的得失也在持续扭曲当下的风险态度。

## 九、时间不一致性

### 大我 vs 小我
- **大我**（t=0 看 t=5）：远期→有小概率特征→高估小概率主导→偏好偏好策略A（趋利避害）
- **小我**（t=4 看 t=5）：近期→无小概率特征→价值函数主导→偏好策略B（更保守）
- 大我的计划 vs 小我的执行→系统性冲突

### 两类人
- **有自知之明**：知道未来小我会变卦→提前承诺约束自己（如设止损单、定投）
- **天真任性**：以为未来会按计划执行→冲动改变→黑格尔："人们往往把任性也叫做自由，但是任性只是非理性的自由"

### 从静态到动态
决策权重的高估小概率效应会反转价值函数描述的风险偏好。从单次决策到多次决策：犯心理错误的机会变多。

## 十、参考点适应 — Arkes, Hirshleifer, Jiang et al. (2008)

### 损益时参考点调整的不对称
- **收益时**：分离两个小收益 v(2)+v(8) > v(10) → 更新参考点更优 → 更容易调整
- **损失时**：合并损失 v(-x)+v(-y) < v(-(x+y)) → 不更新参考点更优 → 更难调整
- **考题核心**：收益区 v 凹→分离收益优于合并→推动参考点上移
  损失区 v 凸→合并损失优于分离→阻碍参考点下移

### 横截面差异
- 西方人→解析思维→注重细节→参考点更新更灵活
- 东方人→整体思维→注重背景和联系→参考点调整存在"负反馈"(δ₂<0)→对整体趋势更敏感，对最新变化反应更慢

## 十一、禀赋效应 (Endowment Effect)

- 一旦拥有某物品，对其估值升高：WTA（愿接受价格）>> WTP（愿支付价格）
- 标准经济学：WTA≈WTP→但现实差距可达2-4倍
- 行为解释：放弃已拥有物品=损失，获得新物品=收益，λ=2.25使损失痛感远超收益快感
- 应用："将欲取之，必先予之"——先试用→改变参考点→提高购买意愿
- 是**维持现状偏差**(Status Quo Bias, Samuelson & Zeckhauser 1988) 和不愿交易的根本原因

---

## 十二、杏仁核——损失厌恶的神经基础

- 杏仁核 = 大脑的"紧急按钮"
- 感知威胁→触发皮质醇分泌（快速释放葡萄糖供能脑部和大肌群）
- 皮质醇→忽略现有记忆，只关注威胁→**注意力狭窄、情绪驱动决策**
- 这就是"情绪劫持"——不是"想太多"，是生物学层面的应激反应
- 解释了为什么损失厌恶如此强大：它根植于生存本能

## 十三、CPT 累积前景理论完整公式（Tversky & Kahneman 1992）

### 价值函数
```
v(x) = x^α                     x ≥ 0
v(x) = -λ·(-x)^β              x < 0
α = β = 0.88,  λ = 2.25
```

### 决策权重函数
```
w+(P) = P^γ / [P^γ + (1-P)^γ]^(1/γ)     γ = 0.61
w-(P) = P^δ / [P^δ + (1-P)^δ]^(1/δ)     δ = 0.69
```

### 累积决策权重
```
收益端（从大到小排序 x₁ > x₂ > ... > 0）：
πᵢ⁺ = w⁺(p₁+...+pᵢ) - w⁺(p₁+...+pᵢ₋₁)

损失端（从小到大排序 x₋ₘ ≤ ... ≤ x₋₁ < 0）：
π₋ₖ⁻ = w⁻(p₋ₘ+...+p₋ₖ) - w⁻(p₋ₘ+...+p₋ₖ₋₁)
```

### 总价值
```
V = Σᵢ πᵢ⁺·v(xᵢ) + Σₖ π₋ₖ⁻·v(x₋ₖ)
```

### 确定性等价
```
CE = V^(1/α)                    V ≥ 0
CE = -((-V)/λ)^(1/β)           V < 0

CE < E[X] → 风险厌恶
CE > E[X] → 风险喜好
```

### 三种参数机制的分工
1. **λ=2.25（损失厌恶）**：将损失端整体放大2.25倍→混合赌局中常使V转负→拒绝→风险厌恶
2. **γ=0.61, δ=0.69（概率加权）**：高估小概率+低估中高概率→纯收益赌局（无损失）中高估小概率主导→CE>E[X]→风险喜好
3. **α=β=0.88（敏感性递减）**：收益凹降低大额收益吸引力，损失凸缓和大额损失边际痛苦（但被λ压倒）
