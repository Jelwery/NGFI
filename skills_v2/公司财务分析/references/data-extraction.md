# 数据提取与验证

## API 提取策略（唯一数据源）

放弃 PDF/OCR 提取。使用 **akshare**（底层数据源：新浪财经，与东方财富/同花顺共享同一套 XBRL 标准化财务数据）直接获取三张表。

```
python scripts/extract_financials.py <股票代码> [--years 5] [--output data.json]
```

示例：
```
python scripts/extract_financials.py 002555              # 三七互娱
python scripts/extract_financials.py 601318 --years 3    # 中国平安（最近3年）
```

### 数据覆盖范围

| 报表 | 字段数 | 说明 |
|------|:---:|------|
| 利润表 | ~83 | 含营业收入→归母净利润全链路，含扣非、EPS |
| 资产负债表 | ~147 | 含所有核心科目，含在建工程、商誉、有息负债等 |
| 现金流量表 | ~71 | 含三类CF及所有子项（直接法） |

**三张表合计 300+ 字段，覆盖分析框架 ~95% 的数据需求（所有比率计算均可直接支撑）。**

### 依赖

```bash
pip install akshare pandas
```

无需 API key，无需注册。

## 数据交叉验证（强制步骤）

**API 数据与交易所 XBRL 同源（历史实测差异 <0.02%）。每轮分析仍须**对以下关键数据用 WebSearch 进行二次确认：

| 必验项目 | 验证来源 |
|---------|---------|
| 归母净利润（近3年） | 东方财富网/新浪财经年报摘要 |
| 基本EPS | 同上 |
| 总资产（年末） | 同上 |
| 营业收入 | 同上（注意区分 CAS vs IFRS 口径） |

若差异 >1%，标注并说明。绝大多数情况下差异应为零（同一数据源）。

## API 无法覆盖的数据（附注层）

以下数据不在三张表的标准化字段中，需从年报附注或 WebSearch 补充：

1. 受限资金金额及明细
2. 在建工程项目明细与预算
3. 大股东股权质押比例
4. 应收账款账龄结构与坏账计提比例
5. 商誉减值测试参数（折现率、增长率）
6. 研发投入资本化率
7. 关联交易明细与定价
8. 短期借款类型（信用/质押/抵押/保证）
9. 诉讼/或有负债

#### 保险企业额外补充项

以下指标对保险企业分析至关重要，但不在三张表标准化字段中，需从 WebSearch/年报单独获取（详见 `references/financial-enterprise.md`"保险专属数据获取指南"）：

10. 内含价值(EV)及每股EV
11. NBV（新业务价值）及增速
12. 综合偿付能力充足率（致命信号检测必用）
13. 综合成本率(COR)（产险）
14. 综合投资收益率
15. ROEV（内含价值营运回报率）

#### 银行企业额外补充项

16. 不良贷款率及拨备覆盖率
17. 核心一级资本充足率

**策略**：优先用 WebSearch 搜索这些信息。搜不到的，在报告中标注"数据未获取，基于可得信息推断"，并相应降低相关结论的置信度。保险企业的EV/NBV无法获取时，P/EV估值跳过，仅用DDM+PB，不可强行估值。

## 数据可信度层级

| 层级 | 标注 | 含义 |
|------|------|------|
| L1 | [API 直接提取] | 从 akshare/Sina API 提取的标准化三张表数据 |
| L2 | [Web 交叉确认] | API 提取后用 WebSearch 确认，或 WebSearch 获取的附注数据 |
| L3 | [研报/媒体引用] | 来自券商研报/财经媒体，未直接验证原始文件 |
| L4 | [合理估算] | 基于行业知识和可得信息的推断 |

估值锚点数据必须达到 L2 以上可信度；L3 数据不能作为估值的单一依据。

## _data.json 输出结构

```
{
  "metadata": {stock_code, sina_code, company_type, periods_count, periods_range,
               errors, year_end_prices, notes_checklist},
  "company_type": "GENERAL|INSURANCE|BANK|BROKER|FINANCIAL_HOLDING|UNKNOWN",
  "annual_data": {"2021": {"利润表": {...}, "资产负债表": {...}, "现金流量表": {...}}, ...},
  "latest_quarter": {"利润表": {...}, ...},       // 最新季度快照（晚于最新年报时存在）
  "prev_year_quarter": {"利润表": {...}, ...}     // 去年同季度快照（用于增量更新同比）
}
```

- `annual_data` 含零值科目（如短期借款=0 时键存在且值为 0；键缺失才代表数据不可得）
- `year_end_prices`：{年份: 年末收盘价}，供 Z 值 X4 逐年计算；获取失败时为空字典
- `prev_year_quarter`：上市不足一年等场景可能缺失，缺失时同比改用年化代理
