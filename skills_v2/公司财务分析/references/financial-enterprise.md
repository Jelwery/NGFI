# 金融类企业特化指南

金融企业（银行/保险/券商/金控集团）在资产负债结构、盈利模式、估值方法上与传统企业有本质差异。在阶段1公司概览中识别出金融企业后，从阶段2开始即应用以下特化规则（非等到阶段3）。**以下规则取代通用规则**。

## 阶段2（利润表）金融特化

- **保险公司**：必须拆解"保险服务业绩"（承保利润/亏损）vs"投资业绩"（利差贡献）。利润引擎分析是保险利润表最核心的工作。
- **核心计算**：
  - 保险服务业绩 = 保险服务收入 - 保险服务费用 - 分出保费净额 - 承保财务损失净额
  - 利差 = 净投资收益率 - 保单负债平均成本
  - 保单负债成本 ≈ 承保财务损失 / 保险合同负债
- **NBV（新业务价值）**是寿险公司最重要的前瞻指标，其重要性高于当期净利润。

## 阶段3（资产负债表）金融特化

- **资产重分类(A/B/C/D)不适用**。改用：
  - ①金融投资资产（按FVTPL/FVTOCI/摊余成本分类）
  - ②银行信贷资产（贷款及垫款）
  - ③现金及流动性资产
  - ④其他资产
- **负债重分类(F/G)不适用**。重点关注：
  - 保险合同负债（保险）或客户存款（银行）——这是金融机构的"核心负债"
  - 负债成本计算
  - 资产负债久期匹配
- **保险专属指标**：偿付能力充足率、保单负债/总资产、利差、投资组合公允价值层级（Level 1/2/3占比）
- **银行专属指标**：不良贷款率、拨备覆盖率、核心一级资本充足率、净息差(NIM)、贷款三阶段分类

## 阶段4（现金流量表）金融特化

- 保险公司经营CF天然远超净利润（保费预收），高位保障倍数不是"质量好"而是行业特征
- 投资CF大额净流出是保费浮存金再投资的正常商业行为，不是"过度投资"
- 保险公司的"投资活动"在实质上就是"经营活动"的一部分（收保费→投出去）

## 阶段5（特殊指标）金融特化

- **Altman Z值：完全不适用金融企业**——跳过，不计算，不展示。替代为偿付能力充足率+不良拨备覆盖率+流动性覆盖率。
- **Beneish M-Score：不适用金融企业**——跳过，不计算，不展示。TATA（应计项）、LVGI（杠杆指数）、GMI（毛利率指数）对金融企业天然失真。替代为**行业专属安全检测框架**（详见`references/stage5-特殊指标分析.md`§5.3金融版）。
- **杜邦分解**可保留但需解读"高杠杆"是行业特征而非风险信号。

## 阶段6（估值）金融特化

- **保险业首选P/EV（内含价值倍数）**，而非P/E或DCF
- DDM可作为绝对估值交叉验证（保险业现金流充裕、分红稳定）
- 标准FCFF/DCF对保险和银行不适用（CAPEX概念无意义）
- 保险业估值框架：
  - 公司价值 = 存量保单价值（EV）+ 未来新业务价值（VNB × 倍数）+ 非保险业务价值
  - P/EV合理倍数判断依据：ROEV是否大于COE
    - ROEV > COE → P/EV应 > 1.0x
    - ROEV ≈ COE → P/EV应 ≈ 1.0x
    - ROEV < COE → P/EV应 < 1.0x

## 保险业专属分析框架（贯穿六阶段）

所有保险公司的分析应以这个框架为"明线"串联六个阶段：

```
保险公司价值 = 存量保单价值（EV）+ 未来新业务价值（VNB）+ 非保险业务价值
              ├─ 阶段2：利润引擎拆解（承保 vs 投资）
              ├─ 阶段3：投资组合+保单负债→利差
              ├─ 阶段4：浮存金机制→现金流验证
              ├─ 阶段5：ROE驱动→偿付能力
              └─ 阶段6：P/EV + DDM 估值
```

## 保险专属数据获取指南

以下关键指标**不在 akshare 标准三张表范围内**，需通过 WebSearch 或年报补充获取：

| 指标 | 用途 | 获取渠道 | 可信度 | 备注 |
|------|------|------|:---:|------|
| **内含价值(EV)** | P/EV估值（权重50%） | 年报"内含价值"章节 / WebSearch搜"{公司} 内含价值 {年份}" / 券商研报 | L2-L3 | 集团EV和寿险EV口径不同，优先用集团EV |
| **每股内含价值** | P/EV估值 | EV ÷ 总股本，或年报直接披露 | L2 | — |
| **NBV（新业务价值）** | 寿险成长性核心指标 | 年报"寿险及健康险"章节 / WebSearch | L2 | 关注NBV增速而非绝对值 |
| **ROEV（内含价值营运回报率）** | 判断P/EV合理倍数 | 年报披露 / EV变动分析表 | L2 | ROEV>COE→P/EV应>1.0x |
| **综合偿付能力充足率** | 致命信号检测+阶段5安全评估 | 偿付能力报告 / 年报"风险管理"章节 / WebSearch | L2 | 监管底线100%，>150%为充裕 |
| **综合成本率(COR)** | 产险承保盈利判断 | 年报"财产保险"章节 / WebSearch | L2 | <100%→承保盈利；>100%→承保亏损 |
| **综合投资收益率** | 利差计算 | 年报"投资组合"章节 / 投资者演示材料 | L2 | 区分净投资收益率与综合投资收益率 |
| **保单负债平均成本** | 利差计算 | 承保财务损失÷保险合同负债均值（可从报表近似） | L2-L3 | 无法直接获取时报导近似值并标注 |

**获取策略**：
1. 先 WebSearch 搜 "{公司简称} {年份}年报 内含价值" 获取券商研报摘要（L2-L3）
2. 如搜到公司年报原文披露数字，可信度升为 L2
3. 完全无法获取时，在报告中标注"EV/NBV数据未获取，P/EV估值跳过，仅用DDM+PB"，不强行估值
4. 偿付能力充足率必须在阶段5致命信号检测前获取——这是保险企业最重要的安全指标。如果WebSearch完全无法获取偿付能力数据，在报告中标注"偿付能力数据未获取，无法完成致命信号检测"，**终止分析**（该指标对保险企业不可缺失）。

## 银行业特化指南

### 阶段2（利润表）—— 银行特化

银行利润表的核心不是"卖了多少产品"，而是"资产端赚了多少 vs 负债端付了多少"：

**核心拆解**：
- **净利息收入** = 生息资产利息收入 - 计息负债利息支出
- **净息差(NIM)** = 净利息收入 / 平均生息资产
- **非利息收入** = 手续费及佣金净收入 + 投资收益 + 公允价值变动 + 汇兑损益
- **信用减值损失（信贷成本）** = 当期计提的贷款减值准备 / 平均贷款余额
- **成本收入比(CIR)** = 业务及管理费 / 营业收入

**分析重点**：
- NIM趋势：收缩还是扩张？生息资产收益率 vs 计息负债成本率各自驱动多少？
- 非利息收入占比：越高→收入多元化越好，但波动可能增加
- 信贷成本方向：上升→资产质量恶化，下降→拨备释放利润（需区分）

### 阶段3（资产负债表）—— 银行特化

银行资产负债表分析聚焦于**资产质量**而非资产结构：

- ①贷款及垫款（按五级分类：正常/关注/次级/可疑/损失）
- ②金融投资（FVTPL/FVTOCI/摊余成本）
- ③现金及存放央行款项（含法定存款准备金）
- ④其他资产

**核心指标**：
- **不良贷款率** = 不良贷款余额 / 贷款总额
- **拨备覆盖率** = 贷款减值准备 / 不良贷款余额
- **核心一级资本充足率(CET1)** = 核心一级资本 / 风险加权资产
- **逾期率** = 逾期贷款 / 贷款总额（前瞻指标，领先于不良率）
- **贷款迁徙率** = 关注类→不良类的迁移比例

### 阶段4（现金流量表）—— 银行特化

银行的现金流量表逻辑与一般企业**完全相反**：
- **经营CF为负是正常经营特征**——发放贷款产生CF流出，这是银行的核心经营活动
- 吸收存款产生CF流入，偿还存款产生CF流出
- 投资CF和筹资CF同样受银行特有的资产负债管理驱动
- 不应套用"经营CF>净利润"的标准判断——对银行不适用

**银行现金流判断准则**：存款增长是否覆盖贷款增长（存贷比趋势）、现金及存放央行是否稳定、是否有流动性危机信号（如被迫高息揽储）。

### 阶段5（特殊指标）—— 银行专有安全检测

Z值和M值跳过。替代为以下**银行专属致命信号**：

| 信号 | 阈值 | 说明 |
|------|:---:|------|
| 不良贷款率 | >5% 且 连续2年上升 | 资产质量系统性恶化 |
| 拨备覆盖率 | <120% | 低于监管最低要求，损失吸收能力不足 |
| CET1 | <7.5%（系统重要性银行）或 <6%（一般银行） | 资本充足性严重不足 |
| NIM | <1.2% 且 连续3年下降 | 核心盈利能力持续恶化 |
| 逾期率/关注率 | 连续3年上升且与不良率剪刀差扩大 | 未来不良暴露的领先信号 |

**7维度安全检测的银行调整**：维度2（准备金）→改为"拨备充足性检查"；维度3（再保险）→跳过；维度6（现金流）→按上述银行特化准则解读。

### 阶段6（估值）—— 银行特化

- **首选 P/B + DDM**：银行利润受拨备政策影响大（P/E可靠性低），PB能反映净资产积累能力
- **P/E 交叉验证**（使用拨备前利润 PPoP 计算更可靠）
- **RIM**：适用于分析 ROE 是否可持续高于 COE
- **估值参数**：需独立假设 NIM 收敛路径、信贷成本正常化路径、RWA 增长假设
- FCFF/DCF 不适用——银行CAPEX无意义

## 券商/投行特化指南

### 阶段2（利润表）—— 券商特化

券商收入结构多元化程度高于银行和保险：

**收入分项**：
- 手续费及佣金收入（经纪+投行+资管）
- 利息净收入（融资融券利息-借款利息）
- 投资收益+公允价值变动（自营交易）
- 其他（汇兑、咨询等）

**分析重点**：
- 收入结构稳定性：经纪收入占比高→市场成交量依赖度大
- 自营交易占比变化：占比上升→利润波动放大
- ROE对杠杆的依赖：券商典型ROE来源是杠杆×利差

### 阶段3（资产负债表）—— 券商特化

- ①客户资金存款和结算备付金（隔离存放，不可动用）
- ②融出资金（两融业务）
- ③金融投资（自营盘，按FVTPL/FVTOCI分类）
- ④买入返售金融资产（质押式回购）
- **关键风险指标**：自营权益敞口/净资产、信用交易杠杆率、流动性覆盖率

### 阶段4（现金流量表）—— 券商特化

- 经营CF高度波动（与市场行情强相关）
- 代理买卖证券款（客户资金）是负债，非自有资金
- 投资CF和经营CF边界模糊（自营交易属于经营活动）

### 阶段5（特殊指标）—— 券商专有致命信号

| 信号 | 阈值 |
|------|:---:|
| 净资本/净资产 | <40%（监管红线附近） |
| 自营权益敞口/净资产 | >80% 且连续亏损 |
| 信用交易（两融）违约率 | 持续攀升 |
| 流动性覆盖率 | <120%（接近监管最低100%） |

### 阶段6（估值）—— 券商特化

- **P/B** 为主（净资产积累能力），但需结合 ROE可持续性判断
- **P/E** 交叉验证（使用剔除自营波动的"经调整净利润"）
- **DDM** 适用（券商分红率通常较高）
- 正常PB应在 1.0-1.5x 区间（除非ROE持续>15%）

## 金控集团特化指南

金控集团（FINANCIAL_HOLDING）旗下通常包含银行+保险+券商+资管等多家子公司：

### 贯穿六阶段的处理原则

1. **阶段1**：WebSearch 确认子公司构成和各板块收入/利润占比
2. **阶段2-5**：按主要收入/利润来源确定一个"主导行业"（如保险占>50%则按INSURANCE处理），各板块按对应行业方法论独立分析
3. **阶段6**：**必须使用SOTP估值**——各子公司独立估值后加总，再加/减集团费用和交叉持股折扣

金控集团的致命信号取各子行业致命信号的**并集**，任一个触发即终止。
