# 第二阶段：利润表分析

## 目标

解析公司盈利从哪里来、质量如何、可持续吗。为阶段6的DCF估值提供核心预测假设（收入增速、毛利率、费用率、税率）。

## 独有要点

### 利润表分析方法论基础

分析利润表前，必须理解以下核心概念，否则容易混淆逻辑关系。

**原生项目 vs 衍生项目**

| 类型 | 定义 | 示例 | 分析含义 |
|------|------|------|---------|
| **原生项目** | 独立来自经济活动核算，具有独立性 | 营业收入、营业成本、三费、投资收益 | 可直接归因分析，是分析的重点 |
| **衍生项目** | 根据会计稽核关系计算得出，依赖其他项目 | 营业总成本、营业利润、净利润 | 取决于原生项目，不要混淆因果关系 |

关键稽核关系（新准则）：
- 营业总成本 = 营业成本 + 税金及附加 + 四费（销售/管理/研发/财务）
- 营业利润 = 营业总收入 - 营业总成本 + 投资收益 + 公允价值变动收益 + 资产处置收益 + 其他收益 - 资产减值损失 - 信用减值损失
- 净利润 = 利润总额（营业利润 + 营业外收支）- 所得税费用
- 归母净利润 = 净利润 - 少数股东损益
- 归母综合收益 = 归母净利润 + 其他综合收益（归母部分）

> 分析时从原生项目出发，理解其变动原因，衍生项目的变动自然得到解释。

**"总额项目"与"其中项目"**

利润表中退格（缩进）列示的项目是"其中项目"——将父级科目中的重要子项目单独披露。忽略其中项目不影响稽核关系。新准则下有3个关键"其中项目"：
1. 财务费用下的"利息支出"和"利息收入"
2. 投资收益下的"对联营企业和合营企业的投资收益"

**经常项目 vs 非经常项目**

| 类型 | 特征 | 处理方式 |
|------|------|---------|
| **经常项目** | 与主营业务直接相关，稳定且可持续 | 预测时保留，给予较高权重 |
| **非经常项目** | 与主营业务无关，偶发性 | 预测时**必须剔除**，仅参考扣非口径 |

即使非经常项目利润占比较高，也不能将其纳入估值预测。必须计算扣非净利润和扣非ROE与扣除前对比，相差较大时需特别警示。

**合并报表 vs 母公司报表**

分析时必须使用**合并报表**。母公司报表仅包含母公司本身+部分子公司（成本法核算），而合并报表包含母子公司完整经济活动。母公司和合并报表的差异主要体现在长期股权投资的处理上。

**收益归属视角**

利润表的本质是解释从营业收入到归母净利润的分配过程。各利益相关者依次参与分配：
- 营业成本 → 分配给上游供应商和员工
- 三费 → 分配给员工（薪酬）、广告商、债权人（利息）
- 税金 → 分配给政府
- 少数股东损益 → 分配给少数股东
- 归母净利润 → 母公司股东（**剩余收益获得者**，最后分配）

### 分析维度

**垂直分析（结构）**：各项目占营业收入百分比，找出成本费用的主要构成
**同比分析（变化）**：当期 vs 上期，识别重大变动及原因
**趋势分析（长期）**：3-5年趋势，判断方向性变化
**分部/产品分析**：按业务线拆分，找出核心利润引擎

### 重点关注的科目
- **营业收入**：量价拆分（微观：价格×销量；宏观：市场总量×市占率），增速驱动因素分析。收入预测有两个方法：①微观角度——分产品进行价格×销量预测（适合消费品），②宏观角度——市场总量×市占率（适合周期性/同质化产品）。收入变化需要区分来自价格还是销量。
- **营业成本**：按原材料/人工/折旧/能源拆分，判断成本刚性。部分行业（如航运、钢铁）营业成本刚性很强，收入端波动时利润剧烈波动（高经营杠杆）
- **销售费用**：投放效率（费用增速 vs 收入增速）
- **研发费用**：费用化 vs 资本化的政策，研发投入效率
- **财务费用**：利息收支细分，存贷利差是否合理
- **非经常性损益**：投资收益、公允价值变动、资产减值、信用减值、政府补助、资产处置收益——逐项判断是否真正"非经常"

### 利润质量判断
- 经营利润 vs 非经常性损益：主营业务贡献了多少利润？
- 归母净利润 vs 少数股东损益：利润有多少真正归属上市公司股东？
- 盈利现金保障倍数（经营CF/净利润）是否持续大于1？

### 关键指标（不罗列公式，按需计算）
必须输出：毛利率、经营利润率、净利率、EBIT利润率、EBIT、EBITDA、NOPLAT(EBIAT)

### 盈利预测假设
基于历史趋势和分析发现，为阶段6估值准备以下假设（不在此阶段做预测，仅基于分析给出建议范围）：

| 参数 | 建议范围 | 主要依据 |
|------|---------|---------|
| 未来3-5年收入增速 | X%-Y% | 行业增速、市占率趋势、产能规划 |
| 毛利率趋势 | 升/稳/降 | 成本结构、竞争格局、提价能力 |
| 销售费用率趋势 | 升/稳/降 | 渠道策略、规模效应 |
| 研发费用率趋势 | 升/稳/降 | 技术战略、资本化政策 |
| 实际所得税率 | X% | 近3年平均，考虑税收优惠持续性 |
