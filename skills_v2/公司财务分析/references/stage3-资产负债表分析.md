# 第三阶段：资产负债表分析

## 目标

评估公司资产质量、负债压力和资本效率。核心问题：公司的钱投到哪里去了？这些投资能产生回报吗？财务结构安全吗？

## 行业判断前置

本阶段的分析框架取决于公司在阶段1已识别的行业属性。进入本阶段时回顾阶段1的结论：

- **已在阶段1确认为金融企业**：直接跳至下方"金融企业资产负债表特化分析"章节，不套用A/B/C/D重分类
- **已在阶段1确认为非金融企业**：执行下方标准分析流程
- **阶段1未覆盖或不确定**（不应出现，如出现则先回阶段1补充判断）：暂用标准框架，但注明后续可能需要修正

## 非金融企业分析

### 资产重分类（核心方法）

不按会计分类（流动/非流动），按经济实质重新分类为四类：

| 类别 | 代码 | 包含科目 |
|------|------|---------|
| **货币资金** | A | 库存现金、银行存款、其他货币资金 |
| **经营性营运资产** | B | 应收票据/账款/融资、预付款、其他应收款、合同资产、存货、其他流动资产等 |
| **长期经营资产** | C | 固定资产、在建工程、使用权资产、无形资产、开发支出、商誉、长期待摊费用、递延所得税资产、其他非流动资产等 |
| **金融投资资产** | D | 交易性金融资产、衍生金融资产、债权投资、其他债权投资、长期股权投资、其他权益工具投资、投资性房地产等 |

分析重点：
- A/(A+B+C+D)：现金充裕度
- B占比：营运资金占用
- C占比：重资产 vs 轻资产
- D占比：是否过度金融化

### 负债重分类（核心方法）

| 类别 | 代码 | 包含科目 |
|------|------|---------|
| **有息负债** | F | 短期借款、交易性/衍生金融负债、一年内到期非流动负债、长期借款、应付债券、租赁负债 |
| **无息负债** | G | 应付票据/账款、预收款、合同负债、应付职工薪酬、应交税费、其他应付款、递延收益等 |

分析重点：
- F/(F+G)：真实杠杆水平
- G占比高 = 对上下游议价能力强（占用他人资金）

### NFA/NFL：判断公司是净现金还是净负债

将货币资金(A)、金融投资资产(D)与有息负债(F)合并，判断公司的净财务状况：

**NFA（净金融资产）= (A + D) - F**

- 如果 **A + D > F** → NFA为正 → 公司是**净金融资产**状态，现金+金融资产足以覆盖全部有息负债
  - 财务稳健，利息收入可能超过利息支出，财务费用为负
  - 公司有"闲置资金"可用于投资或回馈股东
- 如果 **A + D < F** → NFL为正 → 公司是**净金融负债**状态，有息负债超过现金+金融资产
  - 需要依靠经营现金流来偿还债务
  - **NFL/总资产**越高，财务风险越大（超过60%为激进）

> NFA越大的公司，越有能力进行大规模分红、回购或逆周期并购。NFL持续扩大的公司，可能面临流动性压力。

**NFA的变化驱动因素**：
- 经营CF强劲 → NFA增加
- 大额资本支出/并购 → NFA减少
- 分红/回购 → NFA减少
- 增发/新增借款 → NFA增加

**CE（使用资本）vs IC（投资资本）的深层含义**

| 指标 | 公式 | 含义 |
|------|------|------|
| **CE（使用资本）** | 非现金资产 - 无息负债 = 股东权益 + 有息负债 - 现金 | 公司经营**实际动用**的资本。扣除现金是因为现金不直接产生运营利润 |
| **IC（投入资本）** | 总资产 - 无息流动负债 | 从资产端看，债权人和股东投入了多少资本 |

为什么CE要扣除现金？
- 除了金融企业，现金一般并不直接产生运营利润
- 公司是通过"低买高卖"运营活动赚钱，而非"钱生钱"
- 从资产端看：CE = 长期经营资产 + NWC - 无息长期负债 = B + C - G(长期)
- 从负债端看：CE = 股东权益 + 有息负债 - 现金

**使用资本收益率 ROCE = EBIT / CE**，比ROA更准确反映经营资产的回报率。

### 各科目深度检查清单

**货币资金**：计算实际利率 ≈ 利息收入/平均存款，1%-2%为合理区间。低于1%警惕资金占用（大股东隧道行为Tunneling），高于3%可能是非经常性理财收益。其他货币资金（冻结存款、质押存款、银行保证金等）变现能力差，需单独关注。

**应收票据**：区分银行承兑汇票（≈准现金，可贴现，风险极低）和商业承兑汇票（≈应收账款，风险为付款方信用）。计算应收票据/应收账款比率——长期大幅高于应收账款表示下游客户很难赊账，需用票据或现金结算（议价力强）。

**应收账款**：周转天数趋势、账龄结构、前五大集中度、坏账计提是否充分。期末突击确认收入的迹象：Q4营收占比异常高+应收账款同步暴增。**利用应收账款调节利润**：关注11个月收入平均但12月猛增+大部分通过应收产生。将应收账款+合同资产+其他应收款+预付账款四项债权加总，计算占总资产比例。如果占比很高而坏账计提比例很低，稍微调整计提就能对净利润产生巨大影响。

**应收款项融资**：公司将部分银行承兑汇票贴现/背书，或将应收账款进行保理业务。这些操作本质是将应收款"提前变现"，需关注：终止确认的应收款是否真的转移了风险？背书/贴现规模过大可能说明公司现金流紧张。

**合同资产 vs 应收账款**：
- 应收账款：无条件收取合同对价的权利，仅承担信用风险
- 合同资产：有条件的收款权利——除时间外还取决于履约义务等其他条件
- 收款确定性：应收账款 > 合同资产
- 新准则下：合同资产+应收账款=老准则的应收账款

**其他应收款（合计）**：这是资产负债表的"垃圾筐"——应收利息、应收股利、各种赔款罚款、保证金、备用金、员工垫付款等都归入此科目。可能藏匿：截留投资收益、大股东占用上市公司资金、私设小金库、将资金转移到账外。如果其他应收款余额大于应收账款余额，应高度警惕。

**存货**：原材料/在产品/产成品占比变化。产成品占比持续上升→滞销。跌价准备是否充分。原材料大幅储备→看好后市；产成品大幅增加→滞销或待价而沽。特殊行业存货风险：服装/电子/食品行业存货越多风险越大（过季即贬值），农林牧渔存货（生物资产）是造假高危区。

**固定资产**：折旧率是否合理。在建工程长年不转固→推迟折旧的嫌疑。固定资产占比高→重资产运营，经营杠杆大，利润波动剧烈。**折旧政策变更**需特别关注，变更折旧方法/延长折旧年限可"扭亏为盈"。折旧/营业成本比重：轻资产公司低（如海天4.64%），重资产公司高。

**在建工程**：不需要计提折旧。若数额很大且迟迟不转入固定资产：①可能已完工使用但为避免折旧故意不转固；②可能通过虚构在建工程供应商将资金流出再流转回收入（高级造假）。工程物资也合并在此科目中。

**开发支出（研发费用资本化）**：
- 研发支出分为研究阶段（必须费用化）和开发阶段（可资本化）
- **资本化释放的信号**：公司选择将研发投入资本化→未来的摊销（而非当期费用）压力→当期利润被"美化"
- **盈余管理**：研发和开发的区分很难，不同分类影响利润确认时点。资本化率突然大幅上升是危险信号
- **查证方法**：对比同行资本化率。如果同行大多费用化而本公司大量资本化，需警惕
- 研发费用虽是利润扣减项，但在一定程度上反而是"加分项"（对高科技行业）

**商誉**：商誉/净资产>30%需特别关注。对照被并购标的业绩承诺完成情况。商誉只计减值不计摊销，一旦减值不能转回。商誉减值一次性大幅计提→"洗大澡"。

**有息负债**：短贷长投是危险信号。计算NFA = (货币资金+金融投资资产) - 有息负债，负值越大财务风险越高。**借款类型分析**：质押/抵押/保证/信用借款——信用借款占比高说明银行对公司信用评价好。**股权质押风险**：大股东股权质押>50%高危。质押率：主板55%/中小板50%/创业板45%。警戒线140-150%，平仓线120-130%。质押比率高说明公司/大股东严重缺钱。

**合同负债/预收款**：变化方向预示未来收入。持续下降是需求变弱的先行信号。四类高合同负债公司：①产品供不应求（茅台），②连锁服务业会员制，③长周期/大单行业（房地产/设备制造），④软件公司多年期合同。

### 关键指标

必须输出：NWC（净营运资本）、IC（投入资本）、CE（使用资本）、有息负债率、NFA（或NFL）/总资产、存货周转率、应收账款周转率、资产负债率、权益乘数。

NWC = (B类资产) - G类流动负债，正值→需要垫付运营资金，越大效率越低。

## 金融企业资产负债表特化分析

> A/B/C/D资产重分类和F/G负债重分类对金融企业不适用。以下为替代框架。

### 保险业资产分析框架

按经济功能重分类（非按会计流动性）：

| 类别 | 包含科目 | 分析重点 |
|------|---------|---------|
| **①金融投资资产** | FVTPL、FVTOCI债权/权益、摊余成本债权、长期股权投资、投资性房地产 | 配置结构、收益率、公允价值层级 |
| **②银行信贷资产** | 发放贷款及垫款 | 不良率、拨备覆盖率、三阶段分类 |
| **③现金及流动性** | 货币资金、存放央行、同业存放 | 流动性充足度 |
| **④其他资产** | 固定/无形/商誉/递延税等 | 占比极小的运营资产 |

### 保险业负债分析框架

| 类别 | 包含科目 | 分析重点 |
|------|---------|---------|
| **保险合同负债** | 保险/再保险合同负债 | **最核心负债**——规模、成本、久期 |
| **金融负债** | 应付债券、卖出回购、借款 | 期限结构、融资成本 |
| **银行客户存款** | 吸收存款 | 成本率、定期/活期结构 |
| **其他负债** | 应付/应交税费/递延税等 | 营运性负债 |

### 保险业核心分析计算

**利差分析（最重要的结构性指标）**：
```
保单负债平均成本 = 承保财务损失 / 保险合同负债
利差 = 净投资收益率 - 保单负债平均成本
```

> 利差是保险公司盈利能力的核心。利差>1%为健康，利差0-1%为收窄警报，利差<0为倒挂（保险业务在摧毁价值）。

**投资组合公允价值层级**：
- 计算Level 1/2/3各占比
- Level 3 > 10%需警惕估值不透明
- 关注Level 3占比趋势（上升=恶化）

**偿付能力**：
- 综合偿付能力充足率 ≥ 100%（监管底线），>150%为充裕
- 核心偿付能力充足率 ≥ 50%

### 银行业资产分析重点

- 贷款总额及增速
- 不良贷款率（NPL ratio）及趋势
- 拨备覆盖率（>150%为健康）
- 贷款三阶段分类（IFRS 9预期信用损失模型）
- 核心一级资本充足率（CET1）

### 银行业负债分析重点

- 客户存款（核心负债）——规模、成本率、定期/活期比
- 同业负债——依赖度
- 应付债券——期限和融资成本
