# 第四阶段：现金流量表分析

## 目标

验证利润是不是真金白银，判断公司战略执行方向和生命周期阶段。利润是"意见"，现金流是"事实"。

## 独有要点

### 直接法分析

**现金流入结构**：经营/投资/筹资流入占总流入比重。健康公司经营流入应占主导。

**现金流出结构**：重点区分"购建固定资产"（战略投资）vs"投资支付"（理财投资）的比重。

### 经营活动现金流深度分析

**两个核心比率**：
- 营业收入含金量 = 销售商品收到现金/营业收入。>1→回款好，<1→应收堆积
- 盈利现金保障倍数 = 经营CF净额/净利润。>1→利润扎实，<0.5→纸面富贵

**与阶段2结论交叉验证**：如果阶段2判断公司盈利能力很强，但本阶段发现经营CF持续低于净利润，则阶段2的结论需要打折扣。

### 季度经营CF趋势（必做项）

如果有季度数据可用，**必须**列出季度经营CF趋势：

- 列出所有可得季度的经营CF净额（如Q4 2023→Q1 2024→...→最近季度）
- 至少包含过去6个季度的数据
- 连续3个季度以上趋势性下滑 → 在报告中用**粗体/红字标注**
- 季度经营CF转负（从正变负）→ 触发"现金流危机预警"，在所有后续分析中前置讨论
- 趋势图本身不需要图形渲染，用数字序列描述即可（如"239→107→55→6→-18"）

### 阶段2-4交叉预警机制

在完成阶段4的OpCF/NP计算后，**必须**回头与阶段2结论做交叉验证。以下三个条件同时触发时，在报告中明确标注"盈利质量恶化"：

1. **净利润增速 > 收入增速**（阶段2发现）——利润增长部分来自非经营项目
2. **经营CF增速 < 净利润增速**（本阶段发现）——利润增长没有对应现金支撑
3. **存货增速 > 收入增速 + 应付账款增速 < 收入增速**（阶段3+本阶段）——供应商正在收紧信用

前两个条件共同触发代表"利润虚胖"，第三个条件加入代表"供应链压力"。三条件齐备时，应将现金流风险上调为分析报告的中心议题。

### 投资活动现金流分析

#### 战略型投资 vs 理财型投资（精细区分）

投资活动必须拆分为两大类，因为其对价值的影响完全不同：

**第一类：战略型投资（第一性，决定公司未来）**

这是公司战略执行的关键。公司今年的状态由3年前的投资选择决定，3年后的状态由今天的投资选择决定。

**(a) 长期经营资产投资**：
- 长期经营资产净投资 = 购建固定资产/无形资产支付的现金 - 处置固定资产/无形资产收回的现金
- 进一步拆分为：
  - **保全性资本支出** ≈ 折旧摊销总额（维持现有生产规模的最低投资）
  - **扩张性资本支出** = 净投资 - 保全性支出
- 扩张性>0→增长战略，≈0→维持战略，<0→收缩
- 长期资产具有**专用属性**，一旦构建很难用于其他用途，因此决定了公司未来所处的行业和经营特征

**(b) 并购（子公司/联营企业）投资**：
- 并购规模 = 取得子公司支付的现金净额 - 处置子公司收回的现金净额
- 重点分析：
  - 并购标的所在行业：与主业是否一致？上下游关系？战略协同还是追逐热点？
  - 并购价格合理性：对照被并购标的业绩承诺完成情况
  - 商誉累积风险：结合阶段3的商誉分析

**战略型投资总和 = 长期资产净投资 + 并购净投资**

**第二类：理财型投资（第二性，闲散资金管理）**

包括：回收投资收到的现金、取得投资收益收到的现金（股息+利息）、理财产品认购与赎回等。这些科目较多说明公司有余钱在进行现金管理，一般与公司战略关系不大。

理财型投资净额 = 收回投资收到的现金 + 取得投资收益收到的现金 - 投资支付的现金

**两类投资的区别判断**：

| 维度 | 战略型投资 | 理财型投资 |
|------|---------|---------|
| 目的 | 执行公司战略，获取竞争优势 | 闲散资金现金管理 |
| 对价值影响 | **第一性**——决定公司未来盈利 | **第二性**——边际影响 |
| 决策主动权 | 唯一由公司主动控制的变量 | 被动/衍生决定 |
| 可逆性 | 低（专用资产难变现） | 高（金融资产可快速变现） |
| 对应的CF科目 | 购建固定资产+取得子公司 | 投资支付的现金+回收投资 |

> 将理财型投资的大进大出误读为"公司在大举扩张"是常见错误。必须从"投资支付的现金"中区分出哪些是理财滚动、哪些是真正的战略布局。

```
现金自给率 = 经营CF净额 / 战略型投资总和
```
- >1：经营现金流可以覆盖战略投资，不需要外部融资
- <1：需要融资来弥补缺口
- 持续<0.5：严重依赖外部输血

**融资需求 = 战略型投资总和 - 期初货币资金 - 经营CF净额**
- 融资需求<0 → 可以向投资者净支付（分红/回购）

### 筹资活动现金流分析

- 正值：公司还在吸收外部资金（成长期或困境期）
- 负值：公司在回报投资者（分红+还债，通常是成熟期）
- 结合阶段1的战略判断和阶段3的有息负债结构，解读筹资行为

### 三大现金流组合与生命周期判断

| 经营CF | 投资CF | 筹资CF | 企业阶段 | 特征 |
|--------|--------|--------|---------|------|
| + | - | + | 成长期 | 主业造血+积极投资+外部融资 |
| + | - | - | 成熟期 | 主业造血+持续投资+回报股东 |
| + | + | - | 成熟后期 | 主业造血+缩减投资+大量还债分红 |
| - | - | + | 初创/困境反转 | 主业失血+持续投入+靠融资续命 |
| - | + | - | 衰退期 | 主业失血+变卖资产+还债 |

至少用近5年数据判断，单一年的组合可能因特殊事件短暂偏离。

### 三类现金流的时序与逻辑关系

理解三类活动的流入流出**时间顺序**和**发生逻辑**，是解读现金流组合的前提。

**时间顺序**：
```
第一阶段：筹资活动现金流入（股权融资/借款）→ 货币资金
    ↓
第二阶段：投资活动现金流出（建厂/并购）+ 经营活动现金流出（采购/付薪）
    ↓
第三阶段：经营活动现金流入（销售回款）+ 投资活动现金流入（处置资产/投资收益）
    ↓  
第四阶段：筹资活动现金流出（分红/还贷/回购）→ 回馈投资者
```

**发生逻辑（主动权层级）**：

| 活动类型 | 主动性 | 说明 |
|---------|:---:|------|
| **战略投资流出** | 主动 | 唯一由企业当局主动控制的变量——投多少、投哪里、何时投，体现战略管理能力 |
| **经营CF** | 半外生 | 一旦投资完成，经营结果受到外部环境（竞争、需求）影响，存在风险。但公司可通过提价、降本、提效增加弹性 |
| **筹资CF** | 被动/衍生 | 根据前两者的结果"被决定"——基本原则是平衡现金存量，使其基本稳定 |

**投-产-融的因果关系**：
- 投资活动现金流出 → 形成经营资产 → 产生经营现金流入 → 回报投资者
- 投资的本质是**"投入现在，为了换取未来"**
- 成功投资：当期投资流出所产生的未来现金流入足以弥补
- 失败投资：投资流出打了水漂，未来无法产生足够回报

**三类活动对公司价值的影响力**：

| 层级 | 活动类型 | 对价值的影响 |
|:---:|------|------|
| **第一性** | 经营活动 + 战略型投资活动 | 直接创造或摧毁价值，是估值的基础 |
| **第二性** | 理财型投资活动 + 筹资活动 | 边际影响，有效市场下融资活动不产生价值 |

> 分析重点永远是经营和战略投资。不要被大额的理财投资进出或筹资活动迷惑——它们不创造核心价值。

### 间接法分析

关注净利润→经营CF的调节过程中的三个关键驱动力：
1. **非付现成本**（折旧摊销减值）——是否与资产规模匹配
2. **非经营活动损益**（投资/公允价值/财务费用）——剔除后看真实经营
3. **营运资本变动**（应收应付存货的变动）——反映营运效率变化

### 关键指标

必须输出：Capex（资本支出）、Accruals（应计项=净利润-经营CF）、FCF（自由现金流）、现金自给率（经营CF/战略投资总额）。
