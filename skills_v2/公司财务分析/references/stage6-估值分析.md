# 第六阶段：估值分析

## 重要禁令

**绝对禁止以当前股价为锚定进行反向调整！估值全程不得提及、引用、参考当前股价。估值的目的是独立判断内在价值，不是解释市场为什么给出当前价格。**

## 目标

汇总前五阶段的所有关键判断，转化为财务预测假设，运用相对估值法和DCF法计算公司内在价值，并通过多情景分析展示价值区间。

## 估值可行性前置判断

在进入详细预测和估值计算之前，先根据前五阶段的结论判断估值是否可行。如果触发以下任一条件，估值应**降级为定性价值区间判断**，明确告知用户无法给出可靠的内在价值估计，并说明原因：

- FCF连续3年以上为负，且阶段2-4的分析未发现改善迹象
- 公司处于初创期且无稳定经营历史（成立<5年或盈利记录<3年）
- 业务模式发生根本性变化（如重大资产重组、主业变更），历史数据不具备预测参考价值
- 关键财务数据严重缺失，无法构建三表预测

降级处理时，仍完成以下可做部分：可比公司乘数参考（如有）、基于归一化盈利的简化估值区间、账面价值分析（PB法）。明确标注"因[具体原因]，本阶段采用简化估值框架，估值结果仅供参考，不确定性极高"。

## 独有要点

### 财务预测（未来3-5年）

**预测假设来源**：
- 收入增速 → 来自阶段1的行业判断 + 阶段2的历史趋势分析
- 毛利率 → 来自阶段2的成本结构分析 + 阶段1的竞争格局判断
- 费用率 → 来自阶段2的费用分析
- 资本支出 → 来自阶段3的资产结构 + 阶段4的投资活动分析
- 营运资本 → 来自阶段3的周转率分析 + 阶段4的营运资本变动分析
- 税率 → 来自阶段2的实际税率分析

**必须做三张表的预测**，且确保勾稽关系：
- 利润表的净利润 → 进入资产负债表的未分配利润
- 资产负债表的现金变动 → 等于现金流量表的现金净增加额
- 现金流量表的经营CF → 与利润表的净利润通过间接法调节一致

### 相对估值法

1. 选择3-5家可比公司，说明选择理由（业务相似性+规模相近性）
2. 计算可比乘数（PE、PB、PS、EV/EBITDA，使用预测期数据）
3. 取行业平均/中位数
4. 乘以目标公司对应指标 → 得到参考价值区间
5. 讨论：为什么选择这些乘数？各乘数隐含什么假设？哪个更适合本公司？

### 金融企业估值方法选择

**保险业**：
- **首选P/EV（内含价值倍数）**——保险业"黄金标准"
- **DDM（股利贴现模型）**——保险业现金流充裕、分红稳定，DDM比FCFF更适用
- **P/B**——交叉验证
- **FCFF/DCF不适用**——保险业CAPEX无意义，"投资活动"本质上是经营行为

**银行业**：
- **P/B + P/E**——主要方法
- **DDM**——适用
- **剩余收益模型（Residual Income Model）**——可选

**估值锚点（保险业）**：
- 内含价值(EV)数据通常需要从年报"管理层讨论"部分或券商研报获取
- EV的可信度应达到L2以上（即PDF提取+网上确认）
- P/EV合理倍数判断：ROEV > COE → P/EV应>1.0x；ROEV ≈ COE → P/EV≈1.0x

### DCF估值（非金融企业）

**推荐使用FCFF模型**（债务结构相对稳定时）。

### WACC计算——周期中性原则

WACC是DCF估值中对结果冲击最大的单一参数。核心原则：**不要用当前时点的极端利率作为永久假设**。

**为什么重要**：当前时点的无风险利率是周期的产物，不是公司的固有属性。用当前1.7%的Rf做永久假设→WACC偏低→终值偏高约20-30%→在利率低点给出系统性乐观结论。反之在利率高点会系统性低估。

**双WACC框架**：

```
WACC_时点 = 当前Rf + β×ERP + 债务成本×(1-t)×D/(D+E)
WACC_中性 = 5年均值Rf + β×ERP + 债务成本×(1-t)×D/(D+E)
```

| 参数 | 时点WACC | 中性WACC | 获取方式 |
|------|---------|---------|---------|
| 无风险利率Rf | 当日10年国债收益率 | 过去5年10年国债均值 | WebSearch查当前值+历史 |
| 市场风险溢价ERP | 5%-7%（恒定） | 同上 | 学术共识，不随周期变 |
| β | 可比公司去杠杆后加回 | 同上（或向1.0微调） | 可比公司回归/公开数据 |
| 债务成本 | 公司当前借款利率 | 当前+1~2%（利差均值回归） | 阶段3利息支出/有息负债 |
| 资本结构D/(D+E) | 当前值 | 向目标/行业均值回归 | 阶段3计算 |

**估值使用**：
- 中性WACC作为**基准情景**折现率
- 时点WACC作为**敏感性分析**的一个情景
- 在估值报告中显式标注："当前10年国债收益率处于历史X%分位。若向5年均值回归（Y%→Z%），WACC变化约±A bp，估值影响约±B%。"

**其他参数约束**：
- WACC须在6%-12%区间，股权成本须高于债务成本
- 无风险利率取中国10年期国债（代码：CN10YR），非美债
- 如WebSearch无法获取历史均值，退而取当前值并标注"无历史对比，Rf假设可能偏乐观/悲观"

FCFF计算：EBIT×(1-t) + 折旧摊销 - 资本支出 - 营运资本增加

终值：优先使用永续增长法，g不超过长期GDP增速（2%-3.5%）。退出倍数法作为交叉验证。

折现率(WACC)与永续增长率(g)之差至少2%。

### 剩余收益模型（Residual Income Model, RIM）

DCF和相对估值法之外，RIM提供了第三种独立视角，尤其适用于PB与PE关系异常的公司的交叉验证。

**核心原理**：

股权价值 = 当期账面净资产(BVE₀) + 未来剩余收益的现值

```
V₀ = BVE₀ + Σ [REₜ / (1+Ke)ᵗ]
```

其中：
- REₜ（剩余收益）= EPSₜ - Ke × BPSₜ₋₁ = (ROE - Ke) × BPSₜ₋₁
- Ke = 股权成本
- BPS = 每股净资产

**直觉理解**：
- 如果公司只能赚取恰好等于股权成本的利润（ROE = Ke）→ RE = 0 → 价值 = 账面价值（PB = 1）
- 如果公司赚取超过股权成本的利润（ROE > Ke）→ RE > 0 → 价值 > 账面价值（PB > 1）
- 如果公司赚取低于股权成本的利润（ROE < Ke）→ RE < 0 → 价值 < 账面价值（PB < 1）

**脚本实现（calc_rim 双模式）**：

- **锚点 ROE_hist** = 近5年 ROE 中位数（长期可持续水平，抗周期）
- **稳定模式**：最新ROE与锚点差距 ≤20% → 永续公式 `implied_pb = 1 + (ROE_hist − Ke)/(Ke − g)`。ROE_hist < Ke 时 spread 为负 → PB<1 自然成立
- **衰减模式**：最新ROE高于锚点 20% 以上（周期顶部）→ ROE 线性衰减至锚点，逐年折现 `RE_t = (ROE_t − Ke)×BPS_{t−1}`，BPS 按 ROE×留存率增长，衰减后接锚点永续终值。衰减年数由 `--rim-fade-years` 控制（默认5；按阶段1护城河评级调整：宽10/窄5/无3）
- **留存率** = 1 − 近3年均(CF分红/归母净利)；分红字段缺失时按0.5并标注 `retention_source`
- **守卫**：Ke−g ≤1% 报错不收敛；ROE≤0 或 ROE_hist≤0 跳过 RIM

**为什么锚点是历史中枢而非Ke**：持久护城河公司（如连续15年 ROE 30%+）回归的是自己的中枢，而非资本成本；无护城河公司 ROE_hist 自然低于 Ke，衰减后 PB<1 比"停在 PB=1"更准确。"衰减至接近 Ke"对应的是 ROE_hist ≤ Ke 的情形。

**RIM验证要点**：
- RIM得出的每股价值应与DCF法结果接近（差异>20%需解释——RIM通常更保守，DCF的显式增长期隐含更长的超额收益期，方向差异可解释）
- RIM对BPS依赖大，BPS的会计质量直接影响估值可靠性
- 高PB公司如果RIM估值远低于DCF，说明DCF假设的超额收益期比历史隐含的更长，需回头检查DCF的g与增长假设

### 异常收益增长模型（Abnormal Earnings Growth, AEG）

AEG是RIM的"增量版"，解释P/E的合理性：

**P/B取决于剩余收益的总量，P/E取决于剩余收益的增量（增长）**

| 指标 | 取决于 | 说明 |
|------|--------|------|
| **PB（市净率）** | 未来剩余收益的累计现值 | 存量视角——净资产+未来超额收益 |
| **PE（市盈率）** | 剩余收益相对于本期是增加还是减少 | 增量视角——当前盈利×增长预期 |

### Molodovsky效应：PB与PE不一定同向

**Molodovsky效应**揭示了PB与PE之间反直觉的关系：

| 象限 | PE | PB | 含义 | 估值含义 |
|------|:--:|:--:|------|---------|
| **大多数公司** | 高 | 高 | RE>0且增长 | 高增长+高回报，典型好公司 |
| **少数公司** | 低 | 高 | 当前收益异常高，预期利润将回归（RE>0但将下降） | **可能被低估**——短期利润虚高导致PE低，但长期回报能力仍强 |
| **少数公司** | 高 | 低 | 当前收益异常低，预期利润将恢复（RE<0但将上升） | **可能被高估**——短期利润虚低导致PE高，但长期回报能力仍弱 |
| **最差公司** | 低 | 低 | RE<0且恶化 | 价值毁灭型 |

> 核心教训：投资时应关注收益的**持续性**。低PE + 高PB的公司可能因暂时性高收益而被低估（前景光明）；高PE + 低PB的公司可能因暂时性低收益而被高估（前景暗淡）。

**RIM/AEG的估值实践中**：
- 当前ROE远高于历史均值 → 脚本自动进入衰减模式（线性衰减至历史中枢，见上）
- 增长型公司：ROE逐年下降，但BPS逐年上升，两者对抗的结果决定RE的走势
- 成熟型公司：ROE接近Ke，RE≈0，估值≈账面价值

### 估值方法选择的决策框架

根据公司特征选择最合适的方法：

| 公司特征 | 首选方法 | 交叉验证 | 说明 |
|---------|---------|---------|------|
| 成熟稳定盈利 | DCF（FCFF） | 相对估值+DDM | 现金流可预测 |
| 高增长轻资产 | DCF + RIM | 相对估值 | RIM处理高PB合理性 |
| 多元化业务 | SOTP | DCF | 分部独立估值更准确 |
| 金融企业（保险） | P/EV + DDM | PB | 标准DCF不适用 |
| 金融企业（银行） | PB + DDM | PE + RIM | 考虑监管资本约束 |
| 亏损企业/初创 | PS + DCF(归一化) | 实物期权(可选) | PE不可用 |
| 周期股 | 归一化DCF + PB | 相对估值(均值乘数) | 使用标准化利润 |
| 清算/困境 | 资产基础估值 | 清算价值 | DCF不适合 |

### SOTP（分部加总法）——多元化公司必做

**触发条件**：当公司业务板块>2个、且各板块毛利率差异>20pp、或涉及"轻资产+重资产"混合模式时，SOTP是**必做项**（不是可选项）。

**为什么？** 用单一DCF/PE估值多元化公司，相当于把高毛利的互联网服务（75%+ GM）和低毛利的硬件制造（10% GM）强行揉在一起——既低估了优质业务的溢价，又掩盖了劣质业务的拖累。

**SOTP执行步骤**：

1. **业务拆分**：按公司披露的分部（如智能手机、IoT、互联网服务、电动汽车）拆开，每个分部独立估值
2. **各分部估值方法匹配**：

| 业务特征 | 适用方法 | 示例 |
|---------|---------|------|
| 高毛利轻资产（GM>40%，CAPEX/收入<5%） | **P/E** | 互联网服务、软件 |
| 中毛利硬件（GM 15-30%） | **EV/EBITDA 或 P/E** | IoT、消费电子 |
| 低毛利硬件（GM<15%） | **EV/EBITDA 或 P/S** | 智能手机制造 |
| 高增长亏损期新业务 | **P/S 或单独DCF** | 初创期汽车、AI |
| 重资产成熟业务 | **EV/EBITDA 或 PB** | 传统汽车制造 |

3. **各分部估值加总 + 净现金 + 集团费用折减 = 总股权价值**
4. **DCF或整体P/E作为交叉验证**（不是替代）

**SOTP输出要求**：
- 每个分部的收入、毛利率、估值方法、乘数选择理由
- 各分部估值加总表
- 与整体DCF的差异分析——差异>20%时解释原因

### 多情景分析（核心要求）

必须构建**悲观、中性、乐观**三种情景，每种情景有独立的完整假设体系：

| 假设维度 | 悲观 | 中性 | 乐观 |
|---------|------|------|------|
| 收入增速 | 中性基准×0.7 | 基于历史的合理预测 | 中性基准×1.3 |
| 毛利率 | 较历史中枢下滑 | 维持历史中枢 | 较历史中枢改善 |
| 费用率 | 刚性上升 | 维持或小幅优化 | 规模效应明显 |
| WACC | 中性+100bps | CAPM计算值 | 中性-50bps |
| 永续增长率g | 1.5%-2.0% | 2.5%-3.0% | 3.0%-3.5% |

每种情景需独立完成三表预测+DCF计算。以中性情景为基准，悲观-乐观为合理价值区间。

## 估值到决策的翻译框架（报告必含章节）

估值的终点不是"给出一个数字"，而是帮助用户理解**什么情况下值多少钱**，以及**未来什么信号会改变估值判断**。估值阶段完成后，报告中必须包含以下两部分：

### 三情景内在价值区间

将估值结果汇总为悲观/中性/乐观三个情景的内在价值区间，每个情景标注其背后的核心假设逻辑：

| 情景 | 核心假设逻辑 | 内在价值区间 | 该情景发生的条件 |
|------|------|:---:|------|
