# 关键阈值速查

以下阈值贯穿六个阶段，来自课件经验标准和学术研究。遇到对应指标时参照判断：

| 指标 | 阈值 | 判断含义 |
|------|------|---------|
| **毛利率** | >90% / 30-90% / <30% | 垄断地位 / 正常竞争 / 激烈竞争 |
| **ROE** | >2倍贷款利率(约>8%) | 经验优秀线。连续10年>20%为顶级公司 |
| **货币资金实际利率** | 1-2% / <1% / >3% | 正常 / 警惕资金占用或造假 / 非经常理财收益 |
| **有息负债率** | >60% | 财务结构激进 |
| **商誉/净资产** | >30% / >50% | 需特别关注 / 过大概率存在减值风险 |
| **流动比率** | ~2:1 | 传统经验标准（行业差异大，需同行对比） |
| **速动比率** | 0.9-1.0 | 可接受范围 |
| **盈利现金保障倍数** | >1 / <0.5 | 利润扎实 / 纸面富贵 |
| **营业收入含金量** | >1 / <1 | 回款好 / 应收堆积 |
| **大股东质押** | >50% | 高危信号 |
| **研发强度（研发/营收）** | >3% | 高新技术企业认证标准线 |
| **AG（总资产增速）** | <10%正常 / 20-30%预警 / >50%极高风险 | 参照Cooper et al.(2008)，高AG与未来低收益强相关 |
| **Z值（非金融）** | <1.81 / 1.81-2.675 / >2.675 | 高风险 / 灰色预警 / 安全 |
| **M值（非金融）** | >-1.78 | 较高造假风险（概率~76%） |
| **公允价值Level 3占比** | >10% | 警惕估值不透明（金融企业） |
| **WACC** | 6-12% | 合理区间，股权成本须>债务成本 |
| **Ke - g** | ≥2% | DDM/DCF终值计算的最低差值要求 |
| **永续增长率g** | ≤长期GDP增速(2-3.5%) | 不超过经济增长天花板 |

> 这些阈值是经验参考而非绝对标准，必须结合行业特征和公司具体情况判断。

> **Z值对低负债/净现金公司失真**：X4=市值/负债会爆炸性放大，Z>2.675 区域区分度低；此类公司侧重 X1/X2/X3 与趋势，不解读绝对值。
