# 周期诊断参考手册

## IS-LM 模型完整推导

### IS 曲线（产品市场均衡）

**推导起点**：封闭经济下总支出恒等式 Y = C + I + G

**消费函数**：C = c0 + c1 * (Y - T)
- c0：自主消费（与收入无关的基础消费）
- c1：边际消费倾向（MPC），0 < c1 < 1
- 可支配收入 Yd = Y - T

**投资函数**：I = I(i) = e - d * i（简化线性形式）
- e：自主投资（不受利率影响的部分）
- d：投资对利率的敏感度，d > 0
- 利率 i 上升 → 投资下降

**均衡产出（封闭经济）**：
Y = c0 + c1 * (Y - T) + e - d * i + G
整理得：Y = (1/(1-c1)) * (c0 - c1*T + e + G) - (d/(1-c1)) * i

**IS 曲线斜率**：-d/(1-c1)，斜率为负
- d 越大（投资对利率越敏感）→ IS 越平坦
- c1 越大（MPC 越高）→ IS 越平坦
- IS 越平坦 → 利率变动对产出的影响越大

**IS 曲线移动**：
- G 增加 → IS 右移，移动幅度 = deltaG / (1-c1)（乘数效应）
- T 增加 → IS 左移，移动幅度 = -c1 * deltaT / (1-c1)
- 消费者信心上升（c0 增加）→ IS 右移

### LM 曲线（金融市场均衡）

**货币需求**：Md/P = Y * L(i)
- L(i)：货币需求对利率的敏感度，L'(i) < 0
- 利率上升 → 持有货币的机会成本上升 → 货币需求下降
- 收入上升 → 交易需求增加 → 货币需求上升

**货币供给**：Ms/P = M/P（央行外生决定）

**均衡条件**：M/P = Y * L(i)
整理得 LM 曲线：在 (Y, i) 空间中斜率为正

**LM 曲线三段形态**（关键！）：

| 区段 | 利率水平 | LM 斜率 | 含义 |
|------|---------|---------|------|
| 凯恩斯区间 | 极低（接近零） | 接近水平 | 流动性陷阱，货币需求对利率无限弹性 |
| 中间区间 | 正常水平 | 正斜率 | 正常传导 |
| 古典区间 | 极高 | 接近垂直 | 货币需求对利率几乎无弹性 |

**LM 曲线移动**：
- M 增加 → LM 右移（同等利率下产出更高）
- P 上升 → LM 左移（实际货币余额缩水）

### IS-LM 框架下的政策效果

**财政扩张（G 增加）**：
1. IS 右移
2. 新均衡：Y 上升，i 上升
3. 挤出效应：i 上升 → 私人投资 I 下降，削弱了财政扩张的总效果
4. 挤出效应大小判断：
   - LM 越陡峭 → 挤出效应越大（利率上升更多）
   - IS 越平坦 → 利率上升较小但投资受利率影响大
   - 如果货币当局配合宽松（LM 右移）→ 挤出效应被抵消

**货币宽松（M 增加）**：
1. LM 右移
2. 新均衡：Y 上升，i 下降
3. 有效性判断：
   - LM 在凯恩斯区间（流动性陷阱）→ 无效，利率已经最低无法再降
   - LM 在中间区间 → 有效，看斜率
   - LM 在古典区间 → 效果最大但经济已接近充分就业

**政策组合的经典场景**：
- 财政扩张 + 货币紧缩 → 利率大幅上升，产出影响取决于相对力度
- 财政扩张 + 货币宽松 → 产出大幅增加，利率不升或微升
- 财政紧缩 + 货币宽松 → 利率大幅下降，产出影响取决于相对力度

### 中国的 IS-LM 特殊性

中国利率传导机制不完全市场化，IS-LM 应用需注意：
- 国有企业投资对利率不敏感 → d 参数较小 → IS 较陡
- 信贷渠道（银行放贷意愿和额度）比利率渠道更重要
- 利率走廊正在建设但尚未完全取代数量型调控

## AD-AS 模型：从短期到中期

### AD 曲线（总需求）

从 IS-LM 推导：价格水平 P 上升 → 实际货币余额 M/P 下降 → LM 左移 → Y 下降
所以 AD 曲线在 (Y, P) 空间中斜率为负。

**AD 右移因素**：G 增加、M 增加、T 减少、消费者/企业信心上升（c0 或 e 增加）

**AD 左移因素**：G 减少、M 减少、T 增加、信心下降

### AS 曲线（总供给）

**短期 AS（价格粘性）**：水平线
- 凯恩斯情形：价格完全粘性，产出完全由需求决定
- 对应现实中产出远低于潜在产出时

**中期 AS（价格调整）**：向上倾斜
- 从工资设定 WS 和价格设定 PS 推导
- W = Pe * F(u, z)：工资取决于预期价格水平、失业率和制度因素
- P = (1+m) * W：价格是工资的加成
- 合并得：P = Pe * (1+m) * F(u, z)
- 当实际失业率 < 自然失业率 → 工资上涨 → 价格上升 → AS 有向上斜率

**长期 AS（价格完全弹性）**：垂直线
- 古典情形：产出回到自然水平（充分就业产出），价格完全调整
- 在长期，货币中性——货币供给只影响价格，不影响实际产出

**AS 右移（潜在产出增加）**：技术进步、资本积累、劳动力增加、制度改善
**AS 左移（供给冲击）**：油价飙升、自然灾害、劳动力市场监管加强

### 短期到中期的调整过程

1. 起始：在自然产出水平 Yn 的均衡
2. AD 正向冲击（如财政扩张）：短期 Y 和 P 都上升
3. 工人发现实际工资下降（Pe 未调整），上调 Pe
4. Pe 上升 → AS 上移（左移）
5. 新均衡：Y 回到 Yn，但 P 高于原来
6. **核心结论**：需求管理在短期有效，在中期只影响价格

### 对投资的意义

- 如果经济在潜在产出以下（负缺口）→ 刺激政策大概率有效，实际增长有空间
- 如果经济在潜在产出以上（正缺口）→ 刺激政策效果有限，主要推高通胀
- 供给冲击（AS 左移）造成的滞胀 → 货币政策两难：收紧压通胀会加剧衰退，宽松救经济会恶化通胀

## 菲利普斯曲线演变

### 原始菲利普斯曲线（Phillips, 1958）

pi_t = pi_bar + (m+z) - alpha * u_t
- 高失业 → 低通胀，低失业 → 高通胀
- pi_bar：预期通胀，在原始版本中假设为常数

### 附加预期的菲利普斯曲线

pi_t - pi_{t-1} = -alpha * (u_t - un)

**三种预期形成方式**：
1. **静态预期**：pi^e = pi_bar（固定值）— 原始 PC
2. **适应性预期**：pi^e = pi_{t-1}（等于上期通胀）— 通胀惯性
3. **理性预期**：pi^e = E[pi | 所有可得信息] — 政策可能被预期抵消

**工资指数化的影响**：工资越与通胀自动挂钩 → PC 越陡峭 → 失业对通胀的影响更大

### 自然失业率（NAIRU）

自然失业率 un = (m + z) / alpha
- m：加成率（企业定价能力）
- z：制度因素（工会力量、最低工资、失业保障）
- alpha：工资对失业率的敏感度

**当 u = un → 通胀稳定（不加速也不减速）**
**当 u < un → 通胀加速**
**当 u > un → 通胀减速**

### 对投资的意义

- 核心任务：判断 u 相对于 un 的位置，这决定了通胀的走向
- 如果 u 持续低于 un 且没有政策收紧 → 通胀压力积累 → 债券不利
- 如果 u 快速上升接近甚至超过 un → 通胀即将回落 → 降息预期升温 → 债券有利
- 中国的 un 本身在变化（人口老龄化、产业结构转型），需要动态重估

## 奥肯定律

经验关系：delta_Y 比率 ≈ k - beta * delta_u
- 美国：产出增速每低于潜在增速约 2%，失业率上升约 1%（beta ≈ 0.5）
- 不同国家系数不同

用途：从失业率变化反推产出缺口；或从 GDP 增速预测就业市场走向

## 索洛增长模型与增长核算

### 基本索洛模型（无技术进步）

**生产函数**（人均形式）：y = f(k)，满足边际报酬递减 f''(k) < 0

**资本积累方程**：delta_k = s * f(k) - (delta + n) * k
- s：储蓄率
- delta：折旧率
- n：人口增长率

**稳态条件**：s * f(k*) = (delta + n) * k*
- 投资 = 有效折旧
- 此时人均资本和人均产出停止增长

**黄金律**：MPK = delta + n
- 人均消费最大化的资本水平
- 如果 MPK > delta + n → 储蓄不足，增加储蓄可提高消费
- 如果 MPK < delta + n → 过度储蓄（动态无效率）

### 有技术进步的索洛模型

生产函数：Y = F(K, A*L)，其中 A 以速率 g 增长（劳动增强型技术进步）

**有效人均资本积累**：delta_k_tilde = s * f(k_tilde) - (delta + n + g) * k_tilde

**稳态增长率**：
- 总产出 Y：n + g
- 人均产出 Y/L：g
- **人均产出的长期增长率完全由技术进步率 g 决定**

**黄金律（有技术进步）**：MPK - delta = n + g
- 净资本边际产出等于总产出增长率

### 增长核算

Y = A * F(L, K) → delta_Y/Y = alpha * delta_L/L + beta * delta_K/K + delta_A/A
- alpha：劳动收入份额
- beta：资本收入份额
- delta_A/A：全要素生产率（TFP）增长，索洛残差

### 中国的增长现实

1999-2015 年增长来源分解：
- 物质资本：67.9%
- 人力资本：12.5-16%
- TFP：其余

2009 年后（四万亿刺激）：资本贡献率升至 107%，TFP 增长明显放缓。

**投资含义**：
- 资本驱动的增长不可持续 → 传统高投资行业长期回报率下行
- TFP 将成为未来增长的主要来源 → 创新和效率提升领域有结构性机会
- 潜在增速中枢下移是转型期的正常现象

### 条件收敛

索洛模型预测：控制储蓄率、人口增长率等变量后，穷国增速快于富国（向稳态收敛）。
收敛速度约每年 2%，即贫富差距缩小一半约需 35 年。

对新兴市场投资的含义：高增长阶段不可永远持续，随着向稳态靠近，增速会自然放缓。

## 美林时钟详解

### 四个阶段的完整画像

**1. 复苏期（Recovery）**
- 增长：触底回升
- 通胀：仍在低位或继续下行（产能利用率低）
- 央行：维持宽松或开始讨论退出
- 收益率曲线：陡峭化（短端被政策压低，长端反映增长预期改善）
- 权益表现：最优（盈利预期改善 + 估值低位 + 融资成本低）
- 最佳板块：可选消费、金融、工业

**2. 过热期（Overheat）**
- 增长：高于潜在增速（正产出缺口）
- 通胀：加速上行（产能约束、劳动力市场趋紧）
- 央行：加息或准备加息
- 收益率曲线：平坦化（短端受加息影响上升，长端反映通胀预期）
- 权益表现：中等（盈利仍在增长但估值承压）
- 最佳板块：能源、材料、银行

**3. 滞胀期（Stagflation）**
- 增长：放缓（可能因供给冲击或紧缩政策）
- 通胀：仍在高位（成本推动或惯性）
- 央行：两难——加息压通胀还是放松救经济
- 收益率曲线：可能倒挂（短端高企，长端反映衰退预期）
- 权益表现：最差（盈利下行 + 估值承压 + 不确定性高）
- 现金为王，商品有结构性支撑

**4. 衰退期（Recession）**
- 增长：负产出缺口扩大
- 通胀：回落（需求塌陷）
- 央行：降息
- 收益率曲线：重新陡峭化（短端快速下行）
- 债券表现：最优（利率下行 → 资本利得）
- 权益：接近底部区域（降息为下一轮周期铺垫）

### 使用框架时的注意事项

- 周期不是机械循环——有时会跳过某些阶段，有时会来回反复
- 持续时间不确定——美林时钟只给出方向，不给时间
- 需要结合其他指标——不能只用增长和通胀二维判断
- 中国和美国可能处于不同阶段
