# 开放经济参考手册

## 蒙代尔-弗莱明模型（IS-LM-BP）

蒙代尔-弗莱明模型是 IS-LM 在开放经济中的扩展，增加了国际收支（BP）曲线。

### 三条曲线

**IS***（开放经济产品市场）：
Y = C + I + G + NX = c0 + c1*(Y-T) + e - d*i + G + NX(Y, Y*, E)
- NX = 净出口 = 出口 - 进口
- NX 取决于：本国收入 Y（-）、外国收入 Y*（+）、实际汇率 E（+）
- E（直接标价法）= e * P* / P，e 为名义汇率

**LM***（开放经济金融市场）：
M/P = Y * L(i)，与封闭经济相同

**BP（国际收支均衡）**：
国际收支 = 经常账户 + 资本账户 = CA + KA = 0
- CA = NX（简化）
- KA = KA(i - i*)：资本流入取决于利差，利差越大资本流入越多
- BP 曲线的斜率取决于资本流动性：
  - 资本完全流动：BP 水平（i = i*）
  - 资本完全不流动：BP 垂直
  - 资本有限流动：BP 正斜率

### 不同汇率制度下的政策效果

**浮动汇率 + 资本完全流动**：
- 货币扩张：LM 右移 → 利率下降 → 资本外流 → 本币贬值 → NX 改善 → IS 右移 → 产出大幅增加
  - 结论：**货币政策高度有效**
- 财政扩张：IS 右移 → 利率上升 → 资本流入 → 本币升值 → NX 恶化 → IS 左移回到原位
  - 结论：**财政政策完全无效**（完全挤出，挤出的是净出口）

**固定汇率 + 资本完全流动**：
- 货币扩张：LM 右移 → 利率下降 → 资本外流 → 央行干预（卖出外汇、买入本币）→ 货币供给减少 → LM 回到原位
  - 结论：**货币政策完全无效**（央行失去货币自主权，必须干预汇率）
- 财政扩张：IS 右移 → 利率上升 → 资本流入 → 央行干预（买入外汇、卖出本币）→ 货币供给增加 → LM 右移 → 产出大幅增加
  - 结论：**财政政策高度有效**

### 不可能三角（Impossible Trinity）

一个国家不可能同时实现：
1. 固定汇率
2. 资本自由流动
3. 独立的货币政策

**中国的位置**：有管理的浮动汇率 + 有限资本流动 + 货币政策自主
- 中间路线，通过资本管控和汇率弹性来维持三维度某种程度的平衡
- 代价：市场扭曲、套利压力、监管成本

**美国的位置**：浮动汇率 + 资本自由流动 + 货币政策自主
- 选择了 2 和 3，放弃固定汇率

### 对投资的意义

- **美联储政策直接影响中国政策空间**：由于中国资本账户不完全封闭，中美利差扩大 → 资本外流压力 → 人民币贬值压力 → 制约 PBOC 降息空间
- **判断一个开放经济体的政策方向时，必须回答两个问题**：
  1. 该国处于不可能三角的哪个位置？
  2. 当前什么约束最紧？（对 PBOC 来说需要问：汇率约束>增长需求，还是反之？）
- **人民币汇率不仅是贸易问题，也是货币政策约束条件**：如果 PBOC 因贬值压力不敢降息，那降息的利好就难以兑现

## 汇率决定理论

### 购买力平价（PPP）

**绝对 PPP**：E = P/P*
- 同一篮子商品在两个国家以同一货币计价时价格相同
- 长期成立，短期偏离是常态

**相对 PPP**：delta_E/E = pi - pi*
- 汇率变化率 = 两国通胀率之差
- 通胀更高的国家货币倾向贬值

**PPP 对投资者的实际意义**：
- 判断货币在长期是否高估/低估
- 巨无霸指数、OECD PPP 可以作为参考锚
- 人民币是否高估？看 PPP 和实际有效汇率（REER）的偏离程度

### 利率平价（UIP/CIP）

**抵补利率平价（CIP）**：(1+i) = (F/S) * (1+i*)
- 远期汇率 F 由利差决定，套利消除
- 在发达市场中几乎始终成立

**非抵补利率平价（UIP）**：(1+i) = E[Se]/S * (1+i*)
- E[Se] 是预期的未来即期汇率
- 高利率货币预期贬值，低利率货币预期升值
- 实证中 UIP 经常不成立甚至出现方向性反例（UIP 之谜）

**对投资的意义**：
- 中美利差扩大 → 按 CIP 远期人民币应更贬（市场确实定价了）
- 但实际汇率走势不一定按 UIP 走——资本流动、风险情绪、政策干预是更现实的驱动
- 在短期（< 6 个月），汇率主要由资本流动和风险情绪驱动；在中期（1-3 年），经济基本面和利差更关键

### 资产市场说

汇率 = 使国际市场对本国资产和外国资产需求达到均衡的价格

关键驱动变量：
- 相对货币供给（M/M*）：本国货币供给相对增长越快 → 本币贬值压力上升
- 相对实际收入：本国经济增长相对越快 → 本币需求上升 → 升值压力
- 相对利率：名义利率高 → 升值（与 UIP 的预期相反，但实证中高利率货币往往短期走强）

## 国际收支恒等式

**基本恒等式**：
经常账户 + 资本账户 + 金融账户 + 误差与遗漏 ≡ 0（复式记账）

但更有用的是从国民收入恒等式推导的：
NX ≡ (S - I) + (T - G)
= 私人部门储蓄-投资差额 + 政府部门储蓄-投资差额

这揭示了：
- 经常账户顺差 = 本国储蓄大于投资（超额储蓄输出到国外）
- 减少经常账户顺差需要：减少储蓄（刺激消费）或增加投资
- 财政赤字（T - G < 0）如果不被私人部门超额储蓄抵消，会恶化经常账户

**中国的双顺差时期**（~2000-2012）：
- 经常账户顺差 + 资本金融账户顺差
- 之所以能双顺差是因为：资本账户顺差主要来自 FDI 而非热钱；中国通过外汇储备积累吸收顺差压力
- 双顺差已结束，现在是更正常的"一顺一逆"（经常账户顺差 + 资本账户一定程度的逆差）

**对投资的意义**：
- 经常账户顺差收窄甚至转逆 → 人民币存在趋势性贬值压力
- 中国储蓄率的变化（周期下行 + 老龄化）是长期汇率方向的最深层决定因素

## 中美政策周期分化分析框架

当中国和美国处于不同的经济周期/政策方向时，投资者面临两个问题：
1. 两边各自怎么走？
2. 分化的大背景下，各自政策有多大空间？

### 分析步骤

**Step 1：独立诊断两边周期**
用第 1 层和第 2 层的框架，分别判断中国和美国的：
- 产出缺口与通胀方向
- 央行政策立场与下一步预判
- 财政空间与方向

**Step 2：分析分化的性质和程度**
- 方向相反（一边松一边紧）→ 最严重，汇率压力最大
- 方向相同但节奏不同（都在松但一边更激进）→ 较温和，可能有跨市场交易机会
- 方向相同但程度不同（微调 vs 激进调整）→ 分化程度居中

**Step 3：判断约束条件**
- PBOC 面临的是：降息空间被利差约束到什么程度？
- Fed 面临的是：如果全球经济走弱（包括中国减速），还能继续加息吗？
- 谁的政策空间更受限制？受限更大的那一方最终可能需要屈服

**Step 4：映射到资产**

| 场景 | 中国资产 | 美国资产 | 汇率方向 |
|------|---------|---------|---------|
| 中国宽松 + 美国紧缩 | 利多有限（汇贬抵消） | 股市承压（利率上行） | 人民币贬 |
| 中国紧缩 + 美国宽松 | 利空（双杀） | 利多 | 人民币升 |
| 中美同时宽松 | 强利多 | 强利多 | 取决于谁更激进 |
| 中美同时紧缩 | 双杀 | 双杀 | 取决于经济韧性 |

### 近期现实场景

**2022-2023 典型分化**：中国宽松（房地产危机+疫情）vs 美国紧缩（通胀高企）
- 人民币对美元贬至约 7.3
- 中国股市：流动性宽松利多 vs 汇率贬值 + 经济基本面疲弱利空 → 震荡偏弱
- 中国债券：经济弱 + 宽松 → 利多，但中美利差倒挂限制了利率下行幅度
- A 股受益板块：出口型企业（汇率贬值利好）

**2024 年底至 2025 年情景**：中国继续宽松（稳增长）vs 美国转向宽松（通胀回落）
- 方向趋同但出发点不同
- 人民币贬值压力缓解（美国降息缩小利差）
- 中国政策空间扩大（汇率约束减弱）
- 对中资资产整体利多（政策空间 + 汇率企稳 + 外部金融条件改善）

## 货币危机模型

### 第一代危机模型（Krugman, 1979）

**核心逻辑**：基本面驱动的固定汇率崩溃
- 政府持续扩张财政 → 央行被财政支配（印钞填补赤字）→ 外汇储备持续流失
- 当外汇储备不足以维持固定汇率时 → 投机攻击 → 固定汇率崩溃
- **信号**：外汇储备趋势性下降、财政赤字不可持续、国内信贷过度扩张

**现实案例**：1994 年墨西哥比索危机、1997 年泰铢危机

### 第二代危机模型（Obstfeld, 1994）

**核心逻辑**：自我实现的预期驱动
- 即使基本面尚可，如果市场普遍预期固定汇率将崩溃 → 投机攻击
- 攻击本身迫使央行大幅加息来保卫汇率 → 经济代价太大 → 央行放弃固定汇率
- **关键要素**：多重均衡（好均衡 vs 坏均衡），预期自己会实现

**现实案例**：1992 年英镑危机（索罗斯攻击）、1997 年东南亚金融危机中部分国家

### 对投资的意义

- 人民币有管理的浮动汇率制度降低了第一代危机风险（不像固定汇率那样脆弱）
- 但资本外流预期和贬值压力可以形成第二代危机中自我实现的动态
- 对新兴市场投资，必须盯住：外汇储备趋势、短期外债/储备比率、经常账户余额/GDP
- 中国的外汇储备规模（~3 万亿美元）和资本管制提供了防火墙，但历史告诉我们没有人完全免疫

## 中美经济结构差异速查

| 维度 | 中国 | 美国 |
|------|------|------|
| 增长驱动力 | 投资+出口（转型中） | 消费（约 70%） |
| 货币政策框架 | 数量+价格混合，多工具并行 | 价格型，利率走廊 |
| 央行独立性 | 国务院管辖，相对独立 | 法律保障的高度独立 |
| 汇率制度 | 有管理的浮动 | 自由浮动 |
| 资本账户 | 有限开放 | 完全开放 |
| 核心融资方式 | 银行信贷（间接融资为主） | 资本市场（直接融资比重高） |
| 储蓄率 | 高（35-45%） | 低（<20%） |
| 主要宏观风险 | 房地产+地方债+通缩 | 通胀+劳动力市场过热 |
| 长期挑战 | 人口老龄化、增长模式转型 | 财政赤字、政治极化 |
