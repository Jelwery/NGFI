# 政策传导参考手册

## 中美央行工具箱对比

### 美联储（Federal Reserve）

**核心目标（双重使命）**：最大就业 + 价格稳定

**主要工具**：
1. **联邦基金利率（Federal Funds Rate）**：核心政策利率，银行间隔夜拆借利率的目标范围
   - FOMC 每年 8 次会议决定
   - 通过公开市场操作将有效利率维持在目标范围内

2. **利率走廊**：
   - 上限：准备金余额利率（IORB），Fed 支付给银行的准备金利息
   - 下限：隔夜逆回购利率（ON RRP），Fed 支付给货币市场基金等非银机构的利率
   - 走廊宽度通常为 25bp

3. **公开市场操作**：
   - 日常操作：保持利率在走廊内
   - QE（量化宽松）：大规模购买国债和 MBS → 扩表，压低长端利率
   - QT（量化紧缩）：停止再投资或主动缩表 → 金融条件收紧

4. **前瞻指引（Forward Guidance）**：
   - 点阵图（SEP）：每个季度每位 FOMC 委员对未来利率路径的预测
   - 会议纪要（Minutes）：决策讨论的更多细节
   - 主席新闻发布会：语调（鹰派/鸽派）通常比决议本身更影响市场

**Fed 资产负债表结构**：
- 资产端：以国债和 MBS 为主
- 负债端：流通货币 + 银行准备金 + 逆回购

### 中国央行（PBOC）

**核心目标（多层次）**：价格稳定 + 经济增长 + 充分就业 + 国际收支平衡

**主要工具**：

1. **存款准备金率（RRR）**：中国央行最重型的工具
   - 每降 0.5 个百分点释放约 1 万亿长期流动性
   - 目前加权平均法定准备金率约 7%（2024 年后继续下行）
   - 信号极强：降准 = 明确宽松
   - 历史上最高达 21.5%（2011 年）

2. **MLF（中期借贷便利）**：中期政策利率锚
   - 期限：3 个月 - 1 年
   - 需合格抵押品（国债、政策性金融债、高等级信用债等）
   - MLF 利率直接影响 LPR 报价（LPR = MLF 利率 + 银行加点）
   - 每月 15 日操作，市场高度关注量价变化

3. **OMO（公开市场操作）**：短期流动性管理
   - 7 天逆回购利率：核心短期政策利率
   - 14 天、28 天逆回购：跨季/跨年流动性支持
   - 正回购：回收流动性，历史上不常用

4. **SLF（常备借贷便利）**：利率走廊上限
   - 期限：隔夜、7 天、1 个月
   - 利率高于同期限逆回购，构成利率走廊顶部
   - 银行主动申请，央行动用 SLF 说明该机构在银行间市场融资困难

5. **PSL（抵押补充贷款）**：结构性工具
   - 投向特定领域：棚户区改造、保障性住房、基础设施建设
   - 向政策性银行（国开行、农发行、进出口银行）提供

6. **再贷款/再贴现**：支持特定领域
   - 支农再贷款：支持农村金融
   - 支小再贷款：支持小微金融
   - 碳减排支持工具：结构性绿色金融

7. **窗口指导**：非正式但重要的工具
   - 指导银行贷款投放总量和节奏
   - 指导信贷投向（如限制房地产、鼓励制造业和绿色领域）

**中国利率走廊结构**（自上到下）：
- SLF 利率（走廊上限）
- MLF 利率（中期政策锚）
- 7 天逆回购利率（短期政策锚）
- DR007（市场基准利率）
- 超额准备金利率（走廊下限）

**PBOC 资产负债表结构**：
- 资产端：外汇占款 > 对其他存款性公司债权（MLF/PSL）
- 负债端：储备货币（货币发行 + 其他存款性公司存款）
- 关键变化趋势：外汇占款占比下降，对银行债权（MLF 等）占比上升

## 货币乘数与货币创造

### 货币乘数推导

M1 = C + D（流通中现金 + 活期存款）
基础货币 B = C + R（流通中现金 + 准备金）
准备金 R = 法定准备金 RR + 超额准备金 ER

货币乘数 m1 = M1 / B = (C + D) / (C + R)

引入行为参数：
- k = C/D（通货-存款比率，也称为现金漏损率）
- r = R/D（准备金-存款比率，r = rd + re）
- rd：法定准备金率
- re：超额准备金率

m1 = (k + 1) / (k + r) = (1 + k) / (k + rd + re)

**影响货币乘数的因素**：
- rd 下降 → m1 上升（央行降准的目的）
- re 上升（银行惜贷）→ m1 下降 → 货币政策传导受阻
- k 上升（公众偏好现金）→ m1 下降

### 存款创造过程（部分准备金制度）

假设法定准备金率 rd = 20%，初始存款 = 1000 元：

1. 银行 A 收到 1000 存款 → 保留 200 准备金 → 贷出 800
2. 800 存入银行 B → 保留 160 → 贷出 640
3. 640 存入银行 C → 保留 128 → 贷出 512
4. ...

总存款创造 = 1000 / 0.2 = 5000 元（初始存款的 1/rd 倍）
总贷款创造 = 5000 - 1000 = 4000 元

**存款的逆向破坏**：客户提取 1000 元 → 银行存款减少 → 准备金不足 → 收回贷款 → 存款继续减少 → 总存款收缩 5000 元

### 对投资的意义

- RRR 下调释放的流动性通过乘数效应放大，但实际倍数取决于银行放贷意愿和实体融资需求
- 如果 re 很高（银行不愿放贷），降准效果大打折扣 → "推绳子"问题（你可以拉绳子但不能推绳子）
- 信贷增速（社融存量增速）是最终检验：降准 + 乘数 → 信贷扩张 → 经济活动改善

## 货币政策传导渠道

### 渠道一：利率渠道（传统/主流渠道）

政策利率变化 → 短期市场利率变化 → 长期利率变化（通过期限结构预期）→ 投资和消费决策变化 → 总需求变化

**传导效率取决于**：
- 短期利率向长期利率的传导效率（收益率曲线陡峭还是平坦）
- 企业和家庭借贷对利率的敏感度（利率弹性）
- 当前处于 LM 曲线的哪个区段（流动性陷阱中此渠道失效）

**中国特殊之处**：
- 利率传导并不完全市场化，央行仍然影响贷款基准（LPR 报价机制）
- 企业（尤其国企）对利率的敏感度低于对信贷可得性的敏感度
- 存款利率有隐性下限 → 银行息差 → 贷款利率下调空间有限

### 渠道二：信贷渠道（中国最主要渠道）

**银行信贷渠道**：
货币宽松 → 银行准备金增加 → 可贷资金增加 → 贷款供给扩张 → 依赖银行贷款的企业/个人增加支出

**资产负债表渠道**（广义信贷渠道）：
货币宽松 → 资产价格上升 → 抵押品价值上升 → 借款人净值改善 → 外部融资溢价下降 → 借款能力上升

**中国信贷渠道的重要性**：
- 社融（社会融资规模）是最关键的信贷总量指标
- 社融结构变化有意义：人民币贷款 vs 债券融资 vs 影子银行的比重变化反映信用传导的质量
- 窗口指导 + 产业政策结合，信贷可被引导至/撤离特定行业

### 渠道三：资产价格渠道

**托宾 q 效应**：
货币宽松 → 利率下降 → 债券收益率下降 → 股票更有吸引力 → 股价上升 → q = 市值/重置成本 > 1 → 企业增加投资

**财富效应**：
货币宽松 → 资产价格上升 → 家庭财富增加 → 消费增加 → 经济改善

**对投资的意义**：
- 货币宽松推升资产价格 ≠ 经济改善。需要区分"流动性驱动的估值扩张"（第二阶段通常变脆）和"盈利改善驱动的上涨"
- 财富效应在中国较弱（居民资产主要在房地产和存款，股市占比低）

### 渠道四：汇率渠道

货币宽松 → 利率下降 → 资本外流 → 本币贬值 → 净出口改善 → 经济改善

**条件和局限**：
- 必须有资本流动性，这个渠道才有效
- 贬值收益可能被进口成本上升抵消
- 大量外币债务的国家，贬值反而恶化资产负债表（中国外债占比低，这个问题不大）

### 中国传导的特殊阻塞点

与传统教科书不同，中国货币政策传导面临几个特质性阻塞：

1. **利率传导不完善**：政策利率 → 市场利率 → 存贷款利率的传导链不够通畅
2. **银行风险偏好不对称**：宽松时银行惜贷（尤其对中小企业），紧缩时全面收紧
3. **隐性担保和软预算约束**：国有企业、地方政府平台即使利率高也能获得信贷，挤出私人部门
4. **房地产是关键中介**：土地和房产是银行最重要的抵押品，地产下行直接阻塞信贷渠道

## 流动性陷阱详解

### 理论机制

当名义利率接近零时，持有现金的成本趋近于零。此时：
- 货币与债券几乎完全替代
- 货币需求对利率的弹性趋于无穷大（LM 水平）
- 公开市场操作无效——央行用货币换债券，但两者在投资者眼中无差别
- 传统利率渠道失效

### 三个退出选项

1. **量化宽松（QE）**：绕过短端直接购买长期资产，压低长端利率和风险溢价
2. **负利率**：突破零利率下限，但有限度（现金存储成本约 50-100bp）
3. **财政-货币协调**：财政扩张（发行债券）+ 央行购买（货币化）= 本质上是直升机撒钱

### 中国的处境

由于利率尚未达到零（7 天逆回购约 1.5%，MLF 约 2%），中国目前不处于流动性陷阱。但近年利率持续下行，随着利率向零靠近，以数量工具（降准、再贷款）为主的框架需要逐步向价格工具（利率）转型，这是理解 PBOC 工具演变的长期逻辑。

## 财政乘数与挤出效应

### 乘数推导

在 IS-LM 框架中，政府购买乘数（央行不配合时的均衡乘数）：
delta_Y / delta_G = 1 / ((1-c1) + d*k/L')

其中：
- 1/(1-c1)：简单乘数（只有产品市场时）
- d*k/L'：考虑了挤出效应后的修正项
- d 越大（投资对利率越敏感）→ 挤出效应越大 → 均衡乘数越小
- k/L' 越大（LM 越陡峭）→ 挤出效应越大 → 均衡乘数越小

**极限情况**：
- LM 水平（流动性陷阱，L' → 无穷）：乘数 = 1/(1-c1)，完全无挤出，财政政策最有效
- LM 垂直（古典情形，L' → 0）：乘数 → 0，完全挤出，财政政策无效（只推高利率）

### 中国 vs 美国的财政乘数

**美国**：
- MPC 约 0.6-0.8 → 简单乘数约 2.5-5
- 金融市场发达、利率传导通畅 → 挤出效应较大
- 国会预算办公室（CBO）估计的均衡乘数：0.4-2.2（取决于经济状态）
- 经济衰退时乘数更大（因为有闲置资源）

**中国**：
- 高储蓄率 → MPC 约 0.4-0.6 → 简单乘数约 1.7-2.5
- 利率传导不畅 → 挤出效应相对较小
- 实际乘数取决于钱花在哪（基建 > 制造业 > 转移支付）
- 2009 年四万亿托底较大，后续每一轮财政刺激的边际效果递减
- 地方政府土地出让收入收缩严重制约了财政空间

### 债务可持续性速算

债务/GDP 的动态方程：
delta_d = (r - g) * d - pb
- d：债务/GDP 比率
- r：利率
- g：GDP 增速
- pb：基本盈余/GDP

**当 r < g 时，债务/GDP 趋向稳定（即使有赤字）**
**当 r > g 时，债务/GDP 必须靠基本盈余维持才能真正降低**

**中国当前**：r 在下降，g 也在下降。r < g 是否成立取决于两者各自的下降速度。

## 美联储点阵图解读方法

**点阵图结构**：
- 19 个点（7 位理事 + 12 位地区联储行长，每位一票），但 FOMC 投票委员每年只有 12 票
- 每个点代表一位委员对当年末、未来两年、和长期联邦基金利率的预测
- 看"中位数"而非"均值"——中位数点才是市场共识的基准

**解读技巧**：
- 比较当前中位数与上次预测的变化 → 看加息/降息预期的方向变化
- 看点的分布是否收窄或发散 → 委员分歧在扩大还是缩小
- 长期利率预测（较长期的点）→ 市场对中性利率（r*）的共识
- 不要只看中位数——有时候中位数没变，但分布大幅偏移
